# 実在ジムのSNS投稿例観察によるトーン・粒度チューニング(2026-08-07 17:00 UTC)

README.mdの「次にやること」1点目だった、実在の個人経営ボルダリングジムの公式SNSアカウントの
投稿例(公開情報)をWebSearchで観察し、llm-system-prompt-draft.mdの厳守事項4(出力1: SNS投稿文)の
トーン・粒度をチューニングする作業に着手した。

## 観察結果

- 新着課題の告知投稿では、「本日の新課題」「豪華な課題が勢ぞろい✨」のように冒頭で更新自体を
  一言で印象付け、続けて色・グレード帯の範囲(例: 「ピンクから黒帯まで」)と合計本数
  (例: 「全33本」)をセットで明示する型が実例として観察できた
  ([boulderinggym.jp](https://www.boulderinggym.jp/post/%E3%82%AD%E3%83%83%E3%82%BA%E3%82%A6%E3%82%A9%E3%83%BC%E3%83%AB%E5%85%A8%E9%9D%A2%E3%82%BB%E3%83%83%E3%83%88-%E5%AE%8C%E6%88%90))。
- 「課題入れ替え」と同義で「ホールド替え」という言葉も実際のジムのブログ・SNSで使われている
  ([camelopardalis-tokyo.com](https://camelopardalis-tokyo.com/news-blog/))。入力メモ側で
  どちらの語が使われても出力文で意味が通るよう、AI側の語彙選択に含めておく余地がある。
- 課題は「テープ色+級/段(グレード)」で表現するのが一般的で(例: 4級・初段)、
  mvp-flow-draft.md・llm-system-prompt-draft.mdが前提とする入力項目
  (テープ色・グレード帯)と実態が一致していることを確認できた
  ([ninjyaboulder.seesaa.net](http://ninjyaboulder.seesaa.net/article/431856376.html))。
- 個人経営ジム単体の投稿頻度・作成時間・外部委託有無といった定量データは、sns-tone-research.mdの
  調査と同様に今回も公開情報からは見当たらなかった(大手・中堅ジムの公式アカウント/ブログの
  投稿文サンプルが中心)。

## MVP設計への反映

llm-system-prompt-draft.mdの厳守事項4に、以下2点を追記する(下記「変更内容」参照)。

1. 出力1(SNS投稿文)の冒頭付近で、色・グレード帯の範囲と合計本数を要約して明示することを
   明文化する(実例で共通して見られた型のため)。これまでの厳守事項4は「見どころ」を
   1〜2文で紹介する指示のみで、本数・グレード帯の要約を冒頭で示す指示が無かった。
2. 「課題入れ替え」「ホールド替え」のいずれの語が入力メモに使われていても、出力文で
   不自然にならないようにする(AIが入力メモの表現をそのまま尊重しつつ、一般的な
   言い換えとして両者を同義に扱ってよいことを明記)。
