# SNS投稿トーン・粒度に関する追加調査(2026-08-07 13:00 UTC)

mvp-flow-draft.md・llm-system-prompt-draft.mdの「次の課題」だった、実在の個人経営
ボルダリングジムのSNS運用実態のWebSearch調査を行った。

## 調査結果

- クライミングジム・ボルダリングジムのSNS運用は、投稿頻度「週2〜3回」を目安に定期発信で
  フォロワーとの接点を維持することが推奨されている
  ([f-innovations.co.jp](https://www.f-innovations.co.jp/media/sns%E6%98%A0%E5%83%8F%E3%81%A7%E9%AD%85%E3%81%9B%E3%82%8B%E3%82%AF%E3%83%A9%E3%82%A4%E3%83%9F%E3%83%B3%E3%82%B0%EF%BC%81%E3%83%A1%E3%83%B3%E3%83%90%E3%83%BC%E6%8B%A1%E5%A4%A7%E3%81%AE%E6%88%A6/))。
- ハッシュタグ戦略は(1)人気の一般ハッシュタグ(例: #ボルダリング #スポーツクライミング)、
  (2)地域・コミュニティに特化したタグ、(3)ジム独自のオリジナルハッシュタグ(ブランド認知向上目的)、
  の3種類を組み合わせるのが定石とされる。実例として大手ボルダリングジム「グラビティリサーチ」は
  `#グラビティリサーチ` `#スポーツクライミング` `#ボルダリング` のようにブランド名タグ+
  競技名タグを組み合わせている(同上)。
- 個人経営ジムの新着課題更新に特化した投稿文の実例・テンプレートは、今回のWebSearchでは
  公開情報として見当たらなかった(大手チェーンのSNS成功事例の記事が中心で、個人経営ジムの
  投稿頻度・作成時間・外部委託有無に関する定量データも同様に見当たらなかった)。

## MVP設計への反映

- llm-system-prompt-draft.mdの厳守事項4(ハッシュタグ候補)を、単なる一般ハッシュタグの列挙から
  「(1)一般ハッシュタグ、(2)ジム独自のブランドタグ(入力メモまたは店舗設定にジム名がある場合)、
  (3)地域タグ(入力メモに地域名がある場合)」の3種類を組み合わせる方針に具体化する
  (下記「次の課題」で反映予定。店舗名・地域名は入力メモまたは店舗プロフィール設定から
  取得する前提とし、AIが推測で補わない)。
- 投稿頻度「週2〜3回」という情報は、本サービスの投稿"作成"タイミングを縛るものではないが、
  料金プラン検討時の「月あたりの想定利用回数(生成回数)」の目安として参考にできる
  (次の課題の料金プラン仮決めで反映)。
