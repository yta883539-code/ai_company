# サービス紹介ランディングページ(LP)コピー草案

market-research.md(競合・代替手段の仮説)・pricing-plan.md(料金プラン・無料トライアル条件)・
sns-tone-research.md(投稿頻度・ハッシュタグの定石)を踏まえ、想定顧客(個人経営のボルダリング
ジム・クライミングジムのオーナー、複数ジムを掛け持ちするフリーランスのルートセッター)向けに、
サービス自体を紹介するLPのコピー草案を初めて作成する。line-reservation-ai/landing-page-copy-draft.md
と同じ構成(ヒーロー→課題提起→機能紹介→差別化→料金→FAQ)を踏襲しつつ、本venture固有の
「単方向バッチ処理(会話・予約状態管理なし)」「SNS×LINE/Web告知の2経路」という特性を反映する。
実際のLP実装・公開は行わず、文言の草案のみ。

## 想定する読み手

- 個人経営・小規模運営のボルダリングジム・リードクライミングジムのオーナー(ルートセット・
  接客・清掃を兼務)。
- 複数ジムを掛け持ちするフリーランスのルートセッター。
- 課題入れ替え後のSNS投稿・告知文づくりが後回しになりがち、または汎用AIツール(ChatGPT等)に
  毎回ゼロから文脈を説明する手間を感じている(market-research.mdの競合・代替手段の仮説に対応)。

## ファーストビュー(ヒーローセクション)

```
見出し: 課題を入れ替えたら、あとはメモを送るだけ。
サブ見出し: SNS投稿文もLINE告知文も、AIが下書きします。
CTAボタン: 14日間無料で試してみる(カード登録不要)
```
- line-reservation-aiが「予約対応をLINEに任せる」だったのに対し、本ventureの主語は
  「投稿文・告知文づくりをAIに任せる」。オーナー・セッターの作業(セット)を主語にし、
  AI・システムという言葉はヒーローセクションでは使わない方針を踏襲。
- CTA直下の「カード登録不要」はpricing-plan.mdの無料トライアル条件をそのまま反映。

## 課題提起セクション

```
見出し: こんなことに、時間を取られていませんか?
- 課題を入れ替えた後、投稿文を考える時間がなくてSNS更新が翌日以降になってしまう
- 「魅力的な言い回し」を毎回ひねり出すのが、ルートセットとは別の負担になっている
- LINE告知文とSNS投稿文で、同じような文章を2回書き直している
- いつ・どのエリアを・何本入れ替えたか、記録が後回しで曖昧になっている
```
- market-research.mdの「課題(ペインポイント)の仮説」4点(投稿後回し・ライティング負荷・
  二重作業・記録の属人化)を一人称の悩みに変換。3項目目はmvp-flow-draft.mdの出力1・2が
  役割分担された別文面である設計、4項目目は出力3(履歴記録)にそれぞれ対応させ、
  次の機能紹介セクションへの伏線とする。

## 解決策・機能紹介セクション

```
見出し: 「コースセットパシャッと」がやること
1. エリア・テープ色・本数・ムーブの特徴をメモで送るだけ(写真を添えればさらに詳しく)
2. SNS投稿文(Instagram/X向け)の下書きを、ハッシュタグ候補つきで自動生成します
3. 公式LINE/Web告知文の下書きも、SNS投稿とは役割を分けて同時に生成します
4. 「いつ・どのエリアに・何本」入れ替えたか、履歴記録も1行分まとめて作成します
5. 変更のないエリアについて、AIが誤って触れることはありません
```
- 2・3項目目はmvp-flow-draft.mdの出力1(SNS投稿文)・出力2(LINE/Web告知文)、4項目目は
  出力3(履歴記録)、5項目目はllm-system-prompt-draft.mdの厳守事項2(「変更なし」エリアの
  誤記載防止)にそれぞれ対応させ、既存設計と齟齬がないようにした。line-reservation-aiの
  LPが「エスカレーション」を安心材料としたのに対し、本ventureは「誤情報を書かない」ことを
  安心材料とする(会話を伴わないバッチ処理という特性上、人への引き継ぎではなく正確性の
  訴求が適切と判断)。

## 「ゼロから説明しなくていい」を強調するセクション

```
見出し: 汎用AIツールへの説明、もう不要です
グレード表記もムーブの名称もテープ色の慣習も、ボルダリングジム特有の言葉をそのまま
メモに書くだけで伝わります。ChatGPT等に毎回ゼロから文脈を説明する手間はありません。
```
- market-research.mdの「競合・代替手段の仮説」(汎用SNS投稿作成AIツールとの比較優位点)を
  LP向けの短い文に落とし込んだもの。line-reservation-aiの「新しいアプリはいりません」
  セクションと同じ位置づけで、価格訴求より先に体験の違いを提示する。

## 料金・トライアル訴求セクション

```
見出し: まずは14日間、無料でお試しください
- クレジットカードの登録は不要です
- 14日間、または生成5回到達のいずれか早い方まで無料でご利用いただけます
- 期間終了後に自動で課金されることはありません。ご利用実績(生成回数・浮いた作業時間の目安)
  をお送りしますので、続けたい場合のみプランをお選びください
月額1,980円〜(月間生成回数・ご利用セッター人数に応じたプランをご用意しています)
```
- pricing-plan.mdの無料トライアル条件・料金プラン(ライト1,980円/スタンダード3,480円/
  セッター複数5,980円)をそのまま反映。「自動課金しない」方針を明言する点もline-reservation-ai
  と共通させ、申し込みのハードルを下げる。

## よくある質問(FAQ)セクション(案)

```
Q. 複数のジムを掛け持ちしているセッターですが、1人で使えますか?
A. はい。セッター複数プランでは、複数ジム分の投稿・告知文をまとめて管理いただけます。

Q. 写真を送らないと使えませんか?
A. 写真は任意です。メモだけでも投稿文・告知文を生成できます。

Q. グレードやセット内容の最終判断もAIがしてくれますか?
A. いいえ。ルートセット・安全確認・グレーディングの最終判断は、これまで通りセッター様
   ご自身で行っていただきます。本サービスは告知文・記録の下書き作成のみをお手伝いします。
```
- 3問目はREADME.mdの前提(「実際のルートセット作業・安全確認・グレーディングの最終判断は
  セッター本人が行う」)をFAQでも明示し、全自動化への過度な期待を予防する狙い
  (line-reservation-aiのFAQ5問目「難しい相談への対応」と同じ位置づけ)。

## 未検証の仮説・要検証事項

- 「汎用AIツールへの説明が不要」という体験差別化と、「月額1,980円〜」という価格、
  どちらを先に見せた方が申し込み転換率が高いかは未検証(現時点では体験差別化を先に置く仮の順序)。
- AI利用の開示表示義務の要否は、line-reservation-aiのlegal-notices-draft.mdと同様に
  法律専門家への相談が必要な可能性があり、本ドキュメントの範囲では結論を出さない
  (本ventureはまだlegal-notices-draft.mdに相当する文書を作成していない点も次の課題)。
- 実際のLP公開にはドメイン取得・ホスティング・特定商取引法に基づく表記整備が必要で、
  これらは「公開」に該当するため着手時は別途オーナー承認が必要(pending-approval.md参照)。
