# 従量単価(100〜150円/回)の妥当性検証(価値側・市場相場との比較)

作成日: 2026-09-02(フェーズ146)

## 背景

pricing-plan.mdで従量課金方式・単価(ライト150円→スタンダード120円→セッター複数100円/回)を
仮決めし、llm-api-cost-estimate.md(フェーズ81相当)で原価側(Claude API利用料)からは
十分な粗利が残ることを確認済みだった。一方、「未検証の仮説」節に残っていた単価の妥当性検証は
原価側のみで、顧客が実際にその金額を払う価値があると感じるか(価値側)の検証はこれまで
手つかずだった。想定顧客ヒアリング(customer-interview-design.md)は実施自体がオーナー承認
待ちのため、本フェーズでは代替として「同等の作業を人手のクラウドソーシングに発注した場合の
相場」との比較により、価値側からの妥当性を机上検証する。

## 調査方法

WebSearchで「クラウドソーシング SNS投稿文 作成 相場」を検索し、ランサーズ・クラウドワークス
等での実際の発注事例・相場情報を確認した(2026-09-02実施、一次情報の全数調査ではなく
検索結果からの概算)。

## 調査結果(人手発注の相場観)

- ランサーズでのSNS運用代行案件は月額5万〜30万円という表記が多く、単発の投稿文単価としては
  読み取りにくい。実際の案件例では、インスタグラム投稿作成1件あたり予算1万〜2万円(実支払い
  1,000〜2,000円程度)、SNSマーケティング+投稿画像/文章作成一式で1万〜2万円といった価格帯が
  観測された。
- クラウドワークスは時間単価1,200円〜の表記が中心で、1投稿文の作成に10〜20分程度を要すると
  仮定すると、1件あたり200〜400円程度の計算になる。
- 月額契約(SNS運用代行フルパッケージ、投稿文以外の画像制作・投稿作業等も含む)が主流で
  「投稿文の下書き作成のみ」を単発発注する市場は薄いため、上記はいずれも幅のある概算値である。

以上を踏まえると、人手のクラウドソーシング発注では1件あたりおおむね200円〜2,000円程度の
価格帯が観測され、本ventureが仮決めした従量単価(100〜150円/回)は、この価格帯の下限
(200円台)よりもさらに低い。

## 評価

- 原価側(llm-api-cost-estimate.md)・価値側(本ドキュメント)のいずれから見ても、
  100〜150円/回という単価は「原価に対して十分な粗利が残る」かつ「人手発注の相場より安い」
  という二重の意味で妥当、というよりもむしろ保守的(安すぎる可能性がある)側に倒れていると
  評価できる。
- ただし本ventureの提供価値は「投稿文の代筆」ではなく「課題入れ替え後の実施報告・次回案内・
  SNS説明文の3点を、演者が入力する短いメモだけから自動生成し、演者自身の執筆時間そのものを
  削減すること」であり、クラウドソーシングへの外注(演者本人ではない第三者に文章作成を委託
  する行為)とは性質が異なる。人手発注はあくまで「同等の文章作成作業に市場がいくら払っているか」
  の参考値であり、本ventureの価値(演者本人の執筆時間削減・依頼者対応の即応性)を直接測る
  ものではない点には留意が必要。
- 上記の留保はあるが、単価を大幅に引き上げても人手発注の相場より安い水準を維持できる余地が
  あることが分かったため、当面は現行の100〜150円/回を維持しつつ、実際の顧客ヒアリング
  (customer-interview-design.md、オーナー承認待ち)で「高すぎる」という反応が出ない限りは
  単価自体の見直しは急がない、という結論とする。

## 残課題

- 本検証はWebSearchのスニペット調査による概算であり、一次情報(ランサーズ・クラウドワークス
  公式の相場表・分野別カテゴリのレポート)での裏付けは未実施。
- 決済代行サービス側の都度課金対応可否確認(pricing-plan.md未確定事項)は引き続き
  オーナー承認待ちの範囲として残る。
- 実際の想定顧客ヒアリングでの価格感の検証(customer-interview-design.md)は、外部の
  実在事業者への連絡が必要なためpending-approval.md記載の承認待ち事項の範囲内。
