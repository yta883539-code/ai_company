# 初回コンタクト依頼文面(草案)

interview-candidate-selection-criteria.md で整理した選定基準に基づき有力候補として確定した
候補1(FRICTION FREAKS、新潟市西区・個人経営ボルダリングジムオーナー区分、
candidate-longlist-draft.md第四弾参照)への、ヒアリング(customer-interview-design.md、全14問)
協力依頼に使う文面の草案。line-reservation-ai/initial-contact-message-draft.mdの構成を踏襲する。

※本ドキュメントは文面の草案作成のみ。候補1(FRICTION FREAKS)・候補2(AT WALL)等、実在店舗への
実際の送信・連絡は一切行わない。実際の送信は、オーナーが対象候補リストと本文面を確認・承認し、
チャットで直接指示した場合にのみ行う(該当アクションはpending-approval.mdに本フェーズ実施時刻付で
新規記録する)。

## 想定する連絡チャネルと使い分け

| チャネル | 想定ケース | 留意点 |
|---|---|---|
| Instagram DM / 公式SNSのメッセージ機能 | 候補1のように公式Instagramで日常的に新着課題情報を発信している場合 | ジム運営者本人が日常的に確認している可能性が高く最も気軽。文字数は短めに |
| 店舗HPの問い合わせフォーム・メール | 店舗HPに問い合わせフォームがある場合 | 件名で用件が一目でわかるようにする |
| 電話 | 前二者が無く、営業時間中の直接連絡が現実的な場合 | 文面ではなく台本(トーク要点)として使う。ボルダリング利用客対応中の時間帯を避ける |

候補1(FRICTION FREAKS)は公式Instagramで新課題投稿を継続的に行っている実績が確認済み
(candidate-longlist-draft.md第四弾)のため、Instagram DMを第一候補チャネルとする。

## 文面草案A: メール・問い合わせフォーム用(長め)

件名: 【ご協力のお願い】課題入れ替え告知に関する10〜15分程度のヒアリングのお願い

本文:
```
〇〇(ジム名) ご担当者様

突然のご連絡失礼いたします。
私、△△(仮名・個人名は確定候補選定後にオーナーが記入)と申します。

現在、個人経営のボルダリングジム・クライミングジムのオーナー様やルートセッター様向けに、
課題(ルート)入れ替え後の簡単なメモを送るだけで、AIがSNS投稿文・公式LINE/Web告知文・
入れ替え履歴の記録下書きをまとめて生成するサービスを準備しております。

サービス設計にあたり、実際に課題入れ替え時の告知作成でどのような手間や課題を感じて
いらっしゃるか、現場の皆様の声を伺いたく、10〜15分程度のオンラインまたはお電話での
ヒアリングにご協力いただける方を探しております。

・所要時間: 10〜15分程度
・形式: お電話 or オンライン通話(ご都合の良い方法で)
・謝礼: (要検討・下記「未確定事項」参照)
・内容: 現在の課題入れ替え告知の作成方法や困りごとについて、いくつか質問させていただく
  形式です

もしご興味をお持ちいただけましたら、本メールにご返信いただくか、
ご都合の良い日時を2〜3件ほどお知らせいただけますと幸いです。

お忙しいところ恐れ入りますが、ご検討のほどよろしくお願いいたします。

△△
```

## 文面草案B: Instagram DM・チャット用(短め)

```
突然のご連絡失礼いたします。〇〇(ジム名)様の新着課題の投稿、いつも拝見しております。
課題入れ替え時の告知文作成について、10〜15分程度お話を伺えないでしょうか?
個人経営のジム様向けにSNS告知文・入れ替え記録の作成をAIで自動化するサービスを準備しており、
現場の生の声を参考にさせていただきたく、ご協力いただける方を探しております。
ご興味があれば、ご都合の良い日時を教えていただけますと嬉しいです。
```

## 文面草案C: 電話用トーク要点(台本の骨子)

1. 名乗り・突然の連絡へのお詫び
2. 何をしているか一言(個人経営ジム向け課題入れ替え告知AI自動生成サービスを準備中)
3. 依頼内容(10〜15分程度、課題入れ替え告知の作成方法や困りごとについて質問させてほしい)
4. 断られた場合は即座に引き下がり、丁寧にお詫びして電話を切る
5. 快諾いただけた場合は日程調整(customer-interview-design.mdの実施方法に合わせる)

※詳細な進行・想定QAはinterview-rehearsal-script.md(候補1を想定回答者として作成済み)を参照。
