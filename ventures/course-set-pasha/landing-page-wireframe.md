# ランディングページ(LP)ワイヤーフレーム

landing-page-copy-draft.mdの「次のステップ候補」で挙げていたワイヤーフレーム(セクション配置・
画像イメージ)を作成する。aircon-pasha・line-reservation-aiと同様、実装(HTML/CSS)は行わず
テキストベースのワイヤーフレームに留める。LP実装・公開自体は「公開」に該当するため引き続き
オーナー承認後の課題とする。

## 設計方針

- 想定読み手(個人経営ボルダリングジムオーナー・複数ジム掛け持ちのフリーランスセッター)は
  ルートセット直後、店舗のスマートフォンやタブレットで閲覧する比率が高いと想定し、
  aircon-pasha・line-reservation-aiと同様にモバイル1カラムを基本レイアウトとする。
- landing-page-copy-draft.mdのセクション順(ヒーロー→課題提起→機能紹介→「ゼロから
  説明しなくていい」→料金・トライアル→FAQ)をそのまま画面の縦の並びとする。
- 画像方針は他ventureと役割分担する。line-reservation-aiは「LINEトーク画面」、aircon-pashaは
  「メモ→完了報告文のビフォーアフター」を差別化の核心画像としているため、本ventureは
  mvp-flow-draft.mdの出力1(SNS投稿文)を軸に「Instagram投稿プレビュー」をヒーロー画像とし、
  他2ventureと画像コンセプトが重複しないようにする。会話画面ではなく「投稿として公開される
  最終形」を見せることで、SNS運用がサービスの主戦場であることを一目で伝える。

## 画像・ビジュアル方針まとめ

| セクション | 画像案 | 備考 |
|---|---|---|
| ヒーロー | Instagram投稿プレビュー(完成済み投稿を1枚で見せる) | 最優先で作る画像。aircon-pashaのビフォーアフター・line-reservation-aiのトーク画面と役割を分け、「投稿として公開される最終形」を訴求 |
| 課題提起 | 画像なし(テキスト+チェックアイコンのみ) | 共感重視、視覚要素は最小限 |
| 解決策・機能紹介 | 5項目に対応する番号アイコン、5番目のみ区別枠 | 「やらないこと」の明示を視覚的にも区別 |
| 「ゼロから説明しなくていい」 | 画像なし | テキスト訴求のみで十分と判断 |
| 料金・トライアル | 画像なし | 数字とチェックリストで訴求 |
| FAQ | 画像なし | アコーディオンUIのみ |

CTAボタンは「14日間無料で試してみる」の文言・配置(ヒーロー/料金セクション/フッター前の計3箇所)で
統一し、line-reservation-ai・aircon-pashaと表記を揃えた。

## 未確定・今後の課題

- Instagram投稿プレビュー画像そのものの制作(実際の壁面写真・投稿文サンプルを使った
  モックアップデザイン)は本ワイヤーフレームのスコープ外。制作着手時にどのツール・素材を
  使うかは未検討(aircon-pasha/line-reservation-ai共通の課題として、Canva等外部デザイン
  ツール利用はアカウント連携が発生する場合オーナー確認が必要)。
- 実際のHTML/CSS実装、ドメイン取得、ホスティングはいずれも「公開」に該当するため未着手。
  着手にはオーナー承認が必要(pending-approval.md参照)。
- customer-interview-design.mdのヒアリング結果が得られた場合、課題提起セクションの4項目の
