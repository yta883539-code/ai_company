# 冒頭要約(色・グレード帯範囲+合計本数)指示のエッジケース机上検証(2026-08-07 18:00 UTC)

llm-system-prompt-draft.mdの「次の課題」1点目だった、厳守事項4の冒頭要約指示
(色・グレード帯範囲+合計本数を要約して明示する)が、一部エリアのみの入れ替えなど
情報が欠けるケースでも不自然にならないかを、conversation-samples-test-cases.md
(line-reservation-ai)と同様の形式で入力メモ例を作り机上検証した。実LLM呼び出しは
行わず、現行のプロンプト文面をそのまま適用した場合に生成されるはずの出力を人手で
シミュレーションする形の検証(schema-structured-output-compat-checkと同種の机上レビュー)。

## 検証したケース

### ケースA(正常系): 全項目そろっている
入力メモ例:「Aエリア、黄・オレンジテープ(4級〜2級)、8本、カチ持ち系ムーブ中心、2026-08-07改訂」

想定挙動: 色(黄・オレンジ)・グレード帯(4級〜2級)・合計本数(8本)がすべて入力に
明記されているため、厳守事項4通り「黄・オレンジテープ(4級〜2級)を計8本入れ替え」
のような冒頭要約を生成できる。問題なし。

### ケースB: 一部エリアのみ更新、他エリアは「変更なし」
入力メモ例:「Aエリア、赤テープ(1級〜初段)、5本、ダイナミックムーブ中心。Bエリアは
変更なし。2026-08-07改訂」

想定挙動: 厳守事項2(「変更なし」エリアへの新着課題があるかのような表現の禁止)と
厳守事項4(冒頭要約)が同時に適用される。現行文面では「入力メモから読み取れる色・
グレード帯の範囲と合計本数を要約」としか書いておらず、複数エリアが混在した場合に
"要約対象は更新エリアのみ"であることが明示されていない。このままだと、モデルが
誤って「変更なし」のBエリアの情報を合算候補として扱ってしまうリスクは低いものの
(Bエリアの具体的な色・本数情報がそもそも入力に無いため誤合算は起きにくい)、
「Aエリアの新着課題」であることを冒頭要約に明示せず単に「赤テープ(1級〜初段)を
計5本」とだけ書くと、複数エリアを運営するジムでは「今回の更新範囲」が分かりにくい
という別の問題が見つかった。

→ 対応: 更新対象が複数エリア中の一部の場合、冒頭要約に「(対象エリア名)エリアの」を
必ず前置きすることを厳守事項4に追記する(下記「反映内容」参照)。

### ケースC: 本数はあるがグレード帯範囲が入力に無い
入力メモ例:「Aエリア、青テープ、6本、初心者向け中心、2026-08-07改訂」(グレード表記なし)

想定挙動: 現行文面「合計本数・グレード帯の範囲が明記されていない場合は無理に推測で
補わず省略する」は、"本数とグレード帯のどちらか一方でも欠けたら要約全体を省略する"
のか、"欠けている項目だけを省略し、書ける項目(色・本数)だけで要約する"のか、
どちらとも読める曖昧な表現だと判明した。sns-post-example-observation.mdで観察した
実例では、グレード帯が無くても「色+本数」だけの要約(例:「青テープ新着6本」)が
自然に成立しているケースがあり、部分省略(欠けている項目だけを外す)の方が
sns-post-example-observation.mdの実態観察と整合する。

→ 対応: 「合計本数・グレード帯の範囲のうち入力に明記されている項目のみで要約を
構成し、欠けている項目は無理に推測せず要約から外す(両方欠けている場合のみ
要約自体を省略する)」に文言を具体化する。

### ケースD: 色・グレード帯・本数のいずれも入力に無い(特徴のみ)
入力メモ例:「Aエリア、カチ持ち系ムーブを重点強化、2026-08-07改訂」

想定挙動: ケースCの部分省略ルールに従うと、色・グレード帯・本数がすべて欠けている
ため冒頭要約自体を省略し、本文はムーブの特徴紹介から入る構成になる。これは現行
プロンプトの「無理に推測で補わない」方針と矛盾せず、追加の文言修正は不要と判断。

## 反映内容

上記ケースB・Cで見つかった曖昧さを解消するため、llm-system-prompt-draft.mdの厳守事項4
該当箇所を改訂した(次コミットで反映)。

- ケースB対応: 複数エリアのうち一部のみが更新対象の場合、冒頭要約に対象エリア名を
  前置きする一文を追加。
- ケースC対応: 「合計本数・グレード帯の範囲」の省略ルールを、両方欠けている場合のみ
  全体省略、片方のみ欠けている場合は明記されている項目だけで要約を構成する、という
  部分省略ルールに具体化。
