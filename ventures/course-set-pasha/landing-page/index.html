こんなことに、時間を取られていませんか?

  • 課題を入れ替えた後、投稿文を考える時間がなくてSNS更新が翌日以降になってしまう

「コースセットパシャッと」がやること

  1. エリア・テープ色・本数・ムーブの特徴をメモで送るだけ(写真を添えればさらに詳しく)
  2. SNS投稿文(Instagram/X向け)の下書きを、ハッシュタグ候補つきで自動生成します
  3. 公式LINE/Web告知文の下書きも、SNS投稿とは役割を分けて同時に生成します
  4. 「いつ・どのエリアに・何本」入れ替えたか、履歴記録も1行分まとめて作成します
  5. 変更のないエリアについて、AIが誤って触れることはありません

よくある質問

複数のジムを掛け持ちしているセッターですが、1人で使えますか?

はい。セッター複数プランでは、複数ジム分の投稿・告知文をまとめて管理いただけます。

写真を送らないと使えませんか?

写真は任意です。メモだけでも投稿文・告知文を生成できます。

グレードやセット内容の最終判断もAIがしてくれますか?

いいえ。ルートセット・安全確認・グレーディングの最終判断は、これまで通りセッター様ご自身で行っていただきます。本サービスは告知文・記録の下書き作成のみをお手伝いします。

LINEをブロック(友だち解除)すれば解約したことになりますか?

いいえ。LINEのブロックとご契約の解約は別のお手続きです。ブロックのみではご請求は止まりません。ご契約を終了されたい場合は、LINEで「解約したい」とお送りいただくか、お申し込み時にご案内する解約手続きページから直接お手続きください。

複数店舗を運営していますが、店舗ごとに契約が必要ですか?

いいえ。セッター複数プランは、1つの公式LINEアカウントを店舗内の複数スタッフで共有してご利用いただく形を想定しています。店舗ごとに別々のLINEアカウントを使い分けたい場合は、恐れ入りますが店舗ごとにご契約をお願いしております。
