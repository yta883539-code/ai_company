# ヒアリング対象候補(実店舗・セッター)の選定基準・情報源(方法の設計のみ)

customer-interview-design.md「次のステップ候補」で挙げていた、
line-reservation-ai/interview-candidate-selection-criteria.mdに相当する選定基準を
コースセットパシャッと向けに新規作成する。
※本ドキュメントは選定方法の設計のみ。実在店舗・セッターの特定(公開情報の閲覧・記録)は
WebSearchで実行可能だが、実際の連絡・依頼はオーナー許可が必要なアクションのため、
pending-approval.mdに記載した内容に沿ってオーナー承認後にのみ行う。

## 選定基準(仮)

### 必須条件
- 個人経営・小規模運営(スタッフ数目安5名以下、またはオーナー1人でルートセットも兼ねる形態)の
  ボルダリングジム・複合(ボルダリング+リード)ジムであること
  (大手チェーン・フランチャイズ展開のジムは、告知文・SNS運用の意思決定者が本部側にいる
  ことが多く対象外)
- 現在、課題入れ替え後の告知(SNS投稿・LINE/Web告知)を自分で毎回考えて作成していると
  推測できること(既に専属デザイナー・SNS運用代行を使っているジムは課題感が薄く優先度を下げる)
- customer-interview-design.mdの対象区分(個人経営ボルダリングジムオーナー/複合ジムオーナー/
  複数ジム掛け持ちフリーランスセッター)のいずれかに該当すること

### 望ましい条件(優先度を上げる要素)
- 公式SNS(Instagram/X)を運用しており、課題入れ替えの告知投稿を定期的に行っている
  (投稿実績があるほど、投稿頻度・作成の手間についてのヒアリングが具体的になる)
- 複数エリア(初級/中級/上級、テープ色別など)を持ち、課題入れ替えの粒度・頻度に差がありそうなジム
  (mvp-flow-draft.md・multi-area-mixed-case-review.mdで設計した複数エリア対応の妥当性を
  検証しやすいため)
- 公式サイト・SNSのプロフィールに「オーナー1人で運営」「セッター〇名体制」等の運営体制が
  明記されている(意思決定者への直接ヒアリングがしやすい)

### 除外条件
- 全国チェーン・大手フランチャイズ(B-PUMP・ロックランド等の直営店で本部主導のSNS運用を
  行っている店舗)
- ジム紹介・比較を主業務とするポータルサイト運営事業者(ジムの運営自体を行っていないため対象外)

## 情報源(候補)

| 情報源 | 用途 | 留意点 |
|---|---|---|
| Googleマップ(「ボルダリングジム」+地域で検索) | 店舗の存在確認、営業規模・口コミからの運営体制の推測 | 個人が特定できる情報の記録は最小限にとどめる |
| クライミングジム専門ポータル・まとめサイト(公開情報のみ) | 業種別のジム一覧、個人経営か大手チェーンかの一次判別 | ポータル自体は連絡先ではなく情報源としてのみ利用 |
| Instagram/X等のSNS | 課題入れ替え告知の投稿実績・頻度・文面スタイルの事前把握 | フォロワーへの直接的な接触ではなく公開投稿の閲覧に留める |
| クライミング系コミュニティ・SNSでのセッター個人の発信 | 複数ジム掛け持ちフリーランスセッターの候補探し | 個人アカウントへの言及は最小限にし、本人特定情報の記録は控える |

## 選定プロセス(案)

1. 上記情報源から、区分ごとに候補を8〜12件程度リストアップする(ジム名・所在エリア・
   推定運営体制・エリア数・SNS運用実績の有無をメモ)。
2. 除外条件に該当するものを除外し、customer-interview-design.mdの目標合計(7〜9件前後)に対し
   承諾率を考慮して1.5倍程度の候補を用意する(個人経営ジム4〜6件、複合ジム2〜3件、
   フリーランスセッター3〜4件程度を目安に区分ごとに絞り込む)。
3. 絞り込んだ候補リストと、依頼文面(未作成)をセットでオーナーに提示し、連絡の可否・
   優先順位について直接指示を仰ぐ(line-reservation-aiのinterview-request-package.mdに
   相当するパッケージを別途作成する)。
4. オーナー承認後に初めて、pending-approval.mdの記載内容に基づき実際の連絡を行う
   (本エージェントの現在の権限では連絡自体は実施しない)。

## 未検討事項(次のステップ候補)
- 実際の依頼文面(初回コンタクト時のメッセージ)の草案作成
- 区分ごとの候補数の妥当性(承諾率が想定より低い場合の追加候補確保の目安)
- line-reservation-aiで判明した「WebFetchによる公式サイトアクセス拒否」パターンが
  クライミングジムの公式サイトでも起こりうるため、SNS投稿の閲覧(WebSearch結果のスニペット)を
  一次情報源として優先する方針とする
