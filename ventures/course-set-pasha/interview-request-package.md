## 3. 依頼順序の案

1. まず候補1(FRICTION FREAKS)にInstagram DMで連絡し、承諾状況・ヒアリング結果を見る。
2. 候補1の承諾が得られない場合、またはヒアリング後により多くの声が必要な場合に、候補3
   (Speedy)の運営体制をオーナー自身で確認いただいた上で追加連絡を検討する。
3. 候補2(AT WALL)・候補4(Rockmania)は、候補1・候補3の結果を踏まえ、必須条件(個人経営・
   スタッフ数目安5名以下)への該当性がより明確になった場合にのみ連絡対象として検討する。
4. 複合ジムオーナー・フリーランスセッターの2区分は新規候補0件が続いているため、候補1への
   ヒアリング実施後に紹介・口コミ経由で探す方針(candidate-longlist-draft.md第五弾・第八弾の
   申し送り)に委ねる。

## 4. 連絡開始前にオーナー判断が必要な未確定事項(再掲)

initial-contact-message-draft.mdに記載済みの以下の事項は、連絡開始前にオーナーの方針確認が
必要なため未解決のまま残っている。本パッケージ提示にあわせて改めて確認をお願いしたい。

- 謝礼の有無・金額(なし/QUOカード等の少額謝礼/サービス無料トライアル優遇 のいずれにするか)
- 送信者名・会社名・肩書きの表記(個人名か、屋号・サービス名を名乗るか)
- 返信先の連絡先(Instagramアカウント・メールアドレスを新規に用意する必要があれば、それ自体が
  アカウント作成に該当し得るため要検討。該当する場合はpending-approval.mdへの新規記録が必要)
- 候補1以外(候補2〜4、複合ジムオーナー・フリーランスセッターの2区分)への連絡要否・時期

## 5. 未確定事項についての推奨案(オーナー確認用、実行はしない)

line-reservation-aiのinterview-request-package.mdと同種の推奨案を提示する。あくまで提案
であり、いずれも本エージェントが独断で確定・実行することはない。

- **謝礼の有無・金額**: 「なし」を推奨する。金品の謝礼は発送・購入自体が新たな支払い・
  アカウント作成(ギフトカード購入等)を伴いpending-approval.md行きになるため、代わりに
  「ヒアリングにご協力いただいた方には正式ローンチ後、3ヶ月無料+優先案内」という非金銭的な
  謝礼を依頼文面に添える案を提示する(支払い発生なし)。
- **送信者名・会社名・肩書きの表記**: サービス名(屋号)+個人運営である旨を明記する表記を
  推奨する(例:「課題入れ替え告知AI『(サービス名)』を開発している個人開発者の○○です」)。
  法人ではなく個人開発の検証段階であることを正直に伝えたほうが、警戒されにくく承諾率も
  上がりやすいと考えられるため。
- **返信先の連絡先**: 新規のInstagramアカウント・メールアドレスを用意すると、それ自体が
  アカウント作成に該当しpending-approval.md行きになる。オーナーが既存の連絡先を流用する
  運用であれば新規アカウント作成は不要となるため、その方針で問題ないか確認したい(実際の
  アカウント・アドレス自体は本ドキュメントには記載しない)。
- **候補2〜4・2区分保留の扱い**: 候補1への連絡結果が出るまでは対象外のままとし、結果を見て
  追加要否を判断する案を推奨する(「3. 依頼順序の案」と整合)。
