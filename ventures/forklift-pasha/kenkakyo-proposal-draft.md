## 提案パスA: 会員の検査整備事業者向け付加サービス提案

### 想定送付先
建荷協本部(https://www.sacl.or.jp/ 、東京都千代田区神田神保町3-7-1ニュー九段ビル9階)の
会員向け広報担当、または地方支部経由で会員の検査整備事業者(特定自主検査の実施事業者)。

### 件名(案)
フォークリフト等特定自主検査後の記録整形・リマインド業務を軽減するツールのご案内
(会員検査整備事業者様向け)

### 本文下書き
```
公益社団法人建設荷役車両安全技術協会
ご担当者様

突然のご連絡失礼いたします。
貴協会会員の検査整備事業者様が、フォークリフト等の特定自主検査・月次自主検査を実施
された後、検査先の事業者(個人経営・小規模の倉庫業・運送業・建設業等、専任の安全衛生
担当者を置かない事業者様が中心)に対し、検査記録簿の記載事項を満たす記録の整形や、
次回実施期限のリマインドをご案内いただく機会が多いのではないかと存じます。

私どもは、点検・検査の実施者様が検査結果を簡単なメモで送るだけで、AIが
(1)点検記録簿の記載事項を満たす整形、(2)月次自主検査・特定自主検査の次回実施期限の
リマインド通知下書き、をまとめて生成するサービス「フォークリフトパシャっと」を開発して
おります。実際の検査・点検の実施自体、検査結果の良否判断自体は検査整備事業者様・
検査先事業者様が行っていただく前提とし、本サービスは記録整形と期限管理の負担軽減のみを
目的としております。

貴協会会員の検査整備事業者様にとって、検査後の記録作成・顧客への期限案内業務の負担
軽減につながる可能性があると考え、会員様への付加サービスとしてのご提案、または貴協会
経由での会員様へのご紹介の可能性についてお伺いできればと考えております。
ご検討いただけますと幸いです。
```

### 留意点
- 「検査整備事業者が顧客に提供する付加サービス」という位置づけを明確にし、建荷協・
  検査整備事業者の既存業務(検査の実施自体)を代替するものではないことを強調する。
- pricing-plan.mdの料金プラン(保有台数ベース)をそのまま検査整備事業者に提示するか、
  検査整備事業者経由での卸売り・代理店モデルにするかは、実際の交渉時に確定する必要が
  あり、本下書きの段階では言及していない。

### 本文下書き
```
公益社団法人建設荷役車両安全技術協会
機関誌「建設荷役車両」ご担当者様

貴協会が実施されている特定自主検査制度の普及促進・研修教育活動、及び機関誌
「建設荷役車両」での会員事業者様への情報発信に敬意を表します。

私どもは、フォークリフト等の始業前点検・月次自主検査・特定自主検査の実施メモを
送るだけで、AIが点検記録簿の記載事項を満たす整形とリマインド通知下書きを生成する
サービス「フォークリフトパシャっと」を開発しております。専任の安全衛生担当者を
置かない個人経営・小規模の事業者様において、点検記録の作成・期限管理の負担軽減に
つながるものと考えております。

機関誌『建設荷役車両』、または研修・セミナーの場にて、会員事業者様・検査先事業者様向けの
安全衛生関連情報としてご紹介いただける機会がございましたら、資料提供等でご協力させて
いただければと考えております。まずは情報提供の可能性についてお伺いできればと存じます。
```

### 留意点
- パスAと異なり、直接の商業的な提案というより「安全衛生情報の提供」という角度を
  強調し、公益社団法人としての建荷協の事業目的(特定自主検査制度の普及促進)との
  親和性を前面に出す。
- 掲載・紹介には審査や広告掲載料が発生する可能性があり、その場合は支払いが伴うため
  別途pending-approval.mdへの記録が必要になる(本下書きの送信自体も含め、いずれも
  オーナー承認が前提)。
