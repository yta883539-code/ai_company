# ランディングページ(LP)ワイヤーフレーム

landing-page-copy-draft.md(フェーズ57)の「次回候補」1点目で挙げたワイヤーフレーム(セクション
配置・画像イメージ)を作成する。他venture(aircon-pasha・course-set-pasha・kura-pasha・
line-reservation-ai)には既に存在するが本ventureには無かったcross-venture parityのギャップに
対応するもの。他venture同様、実装(HTML/CSS)は行わずテキストベースのワイヤーフレームに留める。
LP実装・公開自体は「公開」に該当するため引き続きオーナー承認後の課題とする。

## 設計方針

- 想定読み手(専任の安全担当者を置かない個人経営・従業員数名規模の倉庫業・運送業・建設業の
  経営者・現場責任者)は、点検の合間・休憩時間にスマートフォンで閲覧する比率が高いと想定し、
  他venture同様モバイル1カラムを基本レイアウトとする。
- landing-page-copy-draft.mdのセクション順(ヒーロー→課題提起→機能紹介→「3区分まとめて
  管理できる」→料金・トライアル→FAQ)をそのまま画面の縦の並びとする。
- 画像方針はaircon-pasha・kura-pashaと同系統(「メモ入力→整形済み記録」というビフォーアフター
  訴求)を踏襲しつつ、本venture固有の「点検種別3区分(daily/monthly/annual)によって記載事項・
  次回期限の算出周期が異なる」という特性を可視化するため、ビフォーアフター画像をdaily・
  monthly・annualの3パターン併記する構成とする(kura-pashaの2パターン〈新規制作/修理〉より
  区分数が多い点が本venture固有)。
- line-reservation-ai(トーク画面中心)・course-set-pasha(SNS投稿プレビュー中心)とは成果物の
  性質が異なり、本ventureはaircon-pasha・kura-pashaと同じく「業務メモ→整形済み記録」という
  変換過程を見せることに絞る。

## 画像・ビジュアル方針まとめ

| セクション | 画像案 | 備考 |
|---|---|---|
| ヒーロー | daily・monthly・annualの3パターンのビフォーアフター(メモ→記録簿1行分) | 最優先で作る画像。タブ/カルーセル切替で「区分ごとに書き分ける」体験を1画面で伝える(本venture固有、kura-pashaは2パターンのみ) |
| 課題提起 | 画像なし(テキスト+チェックアイコンのみ) | 共感重視、視覚要素は最小限(他venture同様) |
| 解決策・機能紹介 | 4項目に対応する番号アイコン、4番目のみ区別枠 | 「やらないこと」の明示を視覚的にも区別 |
| 「3区分まとめて管理できる」 | 画像なし | テキスト訴求のみで十分と判断(aircon-pasha・kura-pashaと同じ扱い) |
| 料金・トライアル | 画像なし | 数字とチェックリストで訴求 |
| FAQ | 画像なし | アコーディオンUIのみ |

CTAボタンは「30日間無料で試してみる」の文言・配置(ヒーロー/料金セクション/フッター前の計3箇所)で
統一し、landing-page-copy-draft.mdの表記と揃えた。
