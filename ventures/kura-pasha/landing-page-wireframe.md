# ランディングページ(LP)ワイヤーフレーム

landing-page-copy-draft.mdの「次のステップ候補」で挙げていたワイヤーフレーム(セクション配置・
画像イメージ)を作成する。他venture(aircon-pasha・course-set-pasha・line-reservation-ai)には
既に存在するが本ventureには無かったcross-venture parityのギャップに対応するもの。他venture
同様、実装(HTML/CSS)は行わずテキストベースのワイヤーフレームに留める。LP実装・公開自体は
「公開」に該当するため引き続きオーナー承認後の課題とする。

## 設計方針

- 想定読み手(乗馬クラブ・牧場からオーダーメイド馬具の制作・修理依頼を受ける個人〜小規模の
  鞍職人・馬具師)は、工房での作業の合間・受注後の空き時間にスマートフォンで閲覧する比率が
  高いと想定し、他venture同様モバイル1カラムを基本レイアウトとする。
- landing-page-copy-draft.mdのセクション順(ヒーロー→課題提起→機能紹介→「まとめて
  書き分けなくていい」→料金・トライアル→FAQ)をそのまま画面の縦の並びとする。
- 画像方針はaircon-pashaと同系統(「メモ入力→整形済み文書」というビフォーアフター訴求)を
  踏襲しつつ、本venture固有の「区分(新規制作/修理)によって出力2(納品案内)の内容が
  分岐する」という特性を可視化するため、ビフォーアフター画像を新規制作用・修理用の2パターン
  併記する構成とする(aircon-pashaは区分が無く1パターンのみだった点との違い)。
- line-reservation-ai(トーク画面中心)・course-set-pasha(SNS投稿プレビュー中心)とは
  成果物の性質が異なり、本ventureはaircon-pasha・course-set-pashaと同じく「業務メモ→
  整形済み文書」という変換過程を見せることに絞る。

## 画像・ビジュアル方針まとめ

| セクション | 画像案 | 備考 |
|---|---|---|
| ヒーロー | 新規制作用・修理用の2パターンのビフォーアフター(メモ→納品案内) | 最優先で作る画像。タブ/カルーセル切替で「区分ごとに書き分ける」体験を1画面で伝える(本venture固有、aircon-pashaは1パターンのみ) |
| 課題提起 | 画像なし(テキスト+チェックアイコンのみ) | 共感重視、視覚要素は最小限(他venture同様) |
| 解決策・機能紹介 | 4項目に対応する番号アイコン、4番目のみ区別枠 | 「やらないこと」の明示を視覚的にも区別 |
| 「まとめて書き分けなくていい」 | 画像なし | テキスト訴求のみで十分と判断(aircon-pashaと同じ扱い) |
| 料金・トライアル | 画像なし | 数字とチェックリストで訴求 |
| FAQ | 画像なし | アコーディオンUIのみ |

CTAボタンは「30日間無料で試してみる」の文言・配置(ヒーロー/料金セクション/フッター前の計3箇所)で
統一し、landing-page-copy-draft.mdの表記と揃えた(他venture〈14日間〉とは期間が異なる点に注意)。

## 未確定・今後の課題

- ビフォーアフター画像そのものの制作(新規制作用・修理用それぞれの実際のメモ例・納品案内
  文サンプルを使ったモックアップデザイン)は本ワイヤーフレームのスコープ外。制作着手時に
  どのツール・素材を使うかは未検討(他venture共通の課題として、Canva等外部デザインツール
  利用はアカウント連携が発生する場合オーナー確認が必要)。
- 実際のHTML/CSS実装、ドメイン取得、ホスティングはいずれも「公開」に該当するため未着手。
  着手にはオーナー承認が必要(pending-approval.md参照)。
- customer-interview-design.mdのヒアリング結果が得られた場合、課題提起セクションの4項目の
  優先順位・アイコンの見せ方を実際の声で見直す(landing-page-copy-draft.mdの既存の
  申し送り事項)。
- 「時給換算」訴求(content-generation-time-estimate.md)を料金セクションに追加するかは
  landing-page-copy-draft.md側で未確定のまま残っており、追加する場合は本ワイヤーフレームの
  料金セクションにも反映が必要。
