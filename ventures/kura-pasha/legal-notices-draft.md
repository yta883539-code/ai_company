README.md「次にやること(候補)」1点目の、legal-notices-draft.md相当の特定商取引法・
プライバシーポリシー文面草案の作成に着手する。構成・書式はaircon-pasha/legal-notices-draft.md・
course-set-pasha/legal-notices-draft.mdを踏襲しつつ、本venture固有の特性(鞍・馬具という
1件あたり高単価・低頻度のオーダーメイド新調/修理、受注内容整理メモ・納品案内下書き・
お手入れ案内下書きの3点セット、対象が鞍職人〈馬具師〉という点)を反映した。

公開そのものはオーナー許可が必要なアクションのためpending-approval.mdに別途記録する。**

## 前提・未確定事項

以下は本サービスの運営主体(個人事業主として営むか法人化するか、屋号、所在地、
連絡先等)がまだ確定していないため、実際の掲載時にはオーナー自身の実情報での

決済代行サービスの選定(line-reservation-aiのdeposit-payment-research.md相当の調査)は

差し替え済み(`user_profile`・`usage_counter`の2種類のみ保有・解約から1年保有)。

## 1. 特定商取引法に基づく表記(案)

本サービスは月額課金のSaaS(役務提供)であり、通信販売の「商品」の売買ではないが、
継続的な役務提供契約として特定商取引法の表示義務(通信販売に準じた運用)の対象と
なりうるため、以下の項目を用意する。line-reservation-ai・aircon-pasha・course-set-pashaの
legal-notices-draft.mdで整理した「役務提供契約も通信販売の表示義務の対象に含まれる
可能性が高い」という調査結果は、サービス形態(月額課金のテキスト生成SaaS)が共通する
ため本ventureにもそのまま準用できると考えられる。

| 項目 | 内容(案) |
|---|---|
| 事業者名 | 【要記入】(個人事業主の場合は屋号+代表者氏名、法人の場合は商号) |
| 代表者 | 【要記入】 |
| 所在地 | 【要記入】(他venture同様、自宅住所の常時表示要否は専門家確認が必要な未確定事項) |
| 連絡先(電話番号・メールアドレス) | 【要記入】 |
| 販売価格 | pricing-plan.mdのプラン案に準拠。「月額980円〜(税込)、プラン詳細は申込フロー内で提示」 |
| 支払方法 | クレジットカード決済(決済代行サービス経由を想定、具体的な決済代行事業者の選定は未着手) |
| 支払時期 | 無料トライアル(初回生成成功から1回無料、または30日間のいずれか早い方)終了後、本人が有料プランを選択した時点から月次自動課金 |
| 提供時期 | 申込完了後、業者がメモを送信できる手段(LINE公式アカウントまたは入力フォーム)の連携設定完了次第、即時利用開始 |
| 返品・キャンセルについて | 役務提供(SaaS利用)のため物理的な返品はなし。契約者はいつでも次回請求サイクル分から解約可能。日割り返金は行わない旨を明記(要確定) |
| 動作環境 | LINE公式アカウントまたはWebフォーム等、職人が受注内容メモを送信する手段(本サービスは受注内容整理メモ・納品案内・お手入れ案内の下書き生成のみを行い、実際の依頼者〈乗馬クラブ・牧場・個人馬主〉への送付は職人本人が行う設計) |

- 「所在地の常時表示要否」「返金ポリシーの詳細」は法律専門家への確認が必要な未確定事項として残す(他venture共通)。
- 決済代行サービスとの加盟店契約には、この特商法表記の整備が前提条件となる(決済代行事業者の選定自体が本ventureの未着手事項)。
- pricing-plan.mdの従量課金(超過分1回あたり150〜250円)は決済代行サービス側の都度課金対応可否確認が前提であり、支払時期・支払方法欄は決済代行サービス選定後に詳細化が必要。

## 2. プライバシーポリシー(案)

### 2.1 取得する情報

- 職人が入力する情報: 受注内容メモ(例:「ブリティッシュ鞍、牛革、競技用、納期3ヶ月」等、
  mvp-flow-draft.md記載の入力フォーマットに準拠。馬体のサイズ・鞍の型・革の種類・
  金具仕様・用途・納期の聞き取り項目を含む。依頼者〈乗馬クラブ・牧場・個人馬主〉本人を
  特定する氏名・住所等の記入は想定しないが、職人が任意にメモへ含めてしまう可能性は
  あるため、取扱い方針を利用規約で明示する必要がある)
- 課金に関する情報: 決済代行サービス経由のクレジットカード情報(本サービス側では非保持、
  決済代行事業者が管理)
- 本サービスは依頼者(エンドユーザー)本人とのやり取りを直接扱わず、職人から職人自身への
  受注内容整理・納品案内・お手入れ案内の下書き作成に特化しているため、依頼者個人の
  連絡先等は原則取得しない設計とする。

### 2.2 利用目的

- 受注内容整理メモ・納品案内下書き・お手入れ案内下書きの生成、本サービスの提供に
  必要な範囲での利用
- LLM(生成AI)API(Claude API等)への問い合わせを通じた、入力メモの解釈・下書き文生成
- サービス改善のための統計的な利用状況分析(個人を特定しない形での集計に限定する方針)

### 2.3 第三者提供・委託

- 入力メモの解釈・下書き文生成のため、外部のLLM APIプロバイダ(Claude API等)に入力内容を
  送信する。プロバイダ側のデータ取り扱い方針(学習利用の有無等)を確認の上、利用規約・
  プライバシーポリシーに委託先として明記する必要がある(現時点でAPIプロバイダ未契約のため
  詳細は今後確認)。
- 決済情報は決済代行サービスに直接入力・管理され、本サービス運営者はカード番号等を保持しない。
- 法令に基づく開示要請があった場合を除き、上記以外の第三者への提供は行わない。

### 2.4 保存期間・削除

- data-retention-policy.md(フェーズ20で新規作成)に基づく正式な記載。本venture固有の
  受注特性(1件あたりの制作期間が長く依頼頻度が低いオーダーメイド中心)を踏まえて
  保有期間の妥当性を検討した結果、`user_profile`が保持するのは屋号・メールアドレス・
  決済ID等の登録情報のみで発注内容自体(鞍の型・革の種類等)は保存しない設計のため、
  依頼頻度の低さ・単価の高さを理由に保有期間を延ばす積極的な根拠はないと判断し、
  他venture(aircon-pasha・course-set-pasha)と同じ1年をそのまま採用した。
- 本サービスが生成する受注内容整理メモ・納品案内・お手入れ案内の文面は、LINE返信
  メッセージ本文等としてその場で返すのみでサーバー側には保存しない設計を想定する
  (入力メモ・生成結果自体の長期保存は発生しない)。
- サーバー側に保存するのは、職人本人に関する情報(`user_profile`: 屋号・事業形態・
  メールアドレス・決済ID等、`usage_counter`: 月間生成回数)の2種類のみを想定。
  トライアル中・有料プラン中は保有継続し、解約(Stripeサブスクリプション解約)から
  **1年**保有した後、削除候補として洗い出す。
- 削除候補化後は職人本人への最終確認(LINE push、またはブロック中はメールでの代替確認)を
  経てから削除する。連絡が取れない場合は自動削除せず、運営者が個別に削除可否を判断する。
- 職人からの開示・削除請求への対応窓口は運営者(本リポジトリのオーナー)とし、LINEの
  `user_id`等を手がかりに該当レコードを検索・削除できれば足りる想定。

### 2.5 未検証・要確認事項

- LLM APIプロバイダとの契約内容(データ学習への利用有無、保存期間、国外移転の有無)は
  APIプロバイダ契約後でないと確定できないため、pending-approval.md記載の
  「実LLM API投入」の承認・契約後に本節を更新する必要がある。
- 「AIが下書き生成に関与していることの開示要否」は、line-reservation-aiのlegal-notices-draft.md
  2.5節・aircon-pashaの同節で整理した調査結果(日本法上は一般的な義務なし)を準用できると
  考えられる。本サービスはcourse-set-pashaと異なりSNS投稿文のような対外広告的な発信は生成せず、
  職人から依頼者への一対一の納品案内・お手入れ案内(aircon-pashaの一対一案内文に近い性質)に
  とどまるため、course-set-pashaで独自に再整理が必要とされたステルスマーケティング規制との
  関係は本ventureでも該当性が薄いと考えられる。あくまでWeb調査による一般的な傾向整理であり
  法的助言ではないため、最終的な要否判断は法律専門家への確認が必要。
- 納品案内・お手入れ案内文に、依頼者の氏名・住所等の個人情報を職人が誤ってメモへ記載して
  しまうケースへの対応方針(本サービス側でのマスキング要否等)は、新たな検討課題として残る
  (aircon-pashaのpost_generation_checks.py相当の仕組みが本ventureには未実装)。
- 2.4節の保存期間はdata-retention-policy.mdに基づく正式な記載へ差し替え済み(フェーズ21)。
