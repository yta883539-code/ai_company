# ステップ3(接続テスト・試験生成)のトーク画面モックスクリプト

## 位置づけ

aircon-pasha/step3-trial-generation-mock-script.md(フェーズ393)と同じ位置づけの文書を、
本venture(kura-pasha)にはまだ作成していなかった(cross-venture parityギャップ)。
onboarding-guide.md「3. 接続テスト・試験生成」は既に入力メモ例(「テスト、区分: 新規制作、
ブリティッシュ鞍、牛革、競技用、納期3ヶ月」)を記載済みだが、これに対応する「業者が
トーク画面で実際に見る一連のやり取り」を文章で示すモックスクリプトは未着手だった。
実LINE公式アカウント・実LLM APIの接続・画像生成は一切行っていない。

## モック対象ケース

output-samples-validation.md記載の`G1_new_basic`(schema/validate_test_cases.py、32件中
パス済み)の入出力を素材にした。`G1_new_basic`の`order_summary.body`
(「区分:新規制作/鞍の型:ブリティッシュ/革の種類:牛革/用途:競技用/納期:3ヶ月」)は
onboarding-guide.mdが既に挙げている試験生成の入力メモ例とほぼ同一であり、新しい事実確認・
WebSearch調査は行わず、既存サンプルの出力フィールド(`order_summary`・`delivery_notice`・
`care_notice`)の内容をそのままトーク画面の文面として再構成した。

## トーク画面の見え方(案)

```
[LINE公式アカウント「(サービス名)」とのトーク画面]

(代表者から送信)
テスト、区分: 新規制作、ブリティッシュ鞍、牛革、競技用、納期3ヶ月

(アプリから自動返信・3つの下書きが連続して届く想定)

――――――――――――――――
【受注内容整理メモ】
区分:新規制作/鞍の型:ブリティッシュ/革の種類:牛革/用途:競技用/納期:3ヶ月
――――――――――――――――
【納品案内 下書き】
新しい鞍をお届けします。装着直後は革が体に馴染むまで時間がかかりますので、最初は
短時間の騎乗から始め、徐々に締め具合を調整してください。雨天時は使用後に乾いた布で
水分を拭き取ってください。
――――――――――――――――
【お手入れ案内 下書き】
定期的にオイル・クリームで革に保湿を与えてください。高温多湿・直射日光を避けた場所で
保管し、カビ・ひび割れを防いでください。金具部分は使用後に乾拭きしさびを防いでください。
――――――――――――――――

この内容で問題なければ、下の2つ(納品案内・お手入れ案内)をそのまま依頼者様への送付文
としてお使いいただけます。表現を直したい場合は、コピーしてから手直しのうえお使いください。
```

## 注記・限界

- 上記は output-samples-validation.md の`G1_new_basic`(机上検証・スキーマ適合済み)の
  出力フィールド内容をそのまま文面化したものであり、実際にLLM APIを呼び出して生成した
  ものではない。実LLM接続後、同じ入力メモに対して実際にこの通りの文面が返るかは引き続き
  未検証(output-samples-validation.md「残る未検証事項」と同じ限界)。
- 本スクリプトは職人向け案内資料(将来のスクリーンショット・操作動画の台本)の素材であり、
  実際の画像・動画の作成、LPやオンボーディングガイドへの画像としての埋め込みは行っていない。
- ステップ2(友だち追加・連携コード発行)は実際の公式アカウント名・QRコードを要するため、
  aircon-pashaと同様、実LINE API接続(オーナー承認待ち)にあわせて着手するのが効率的と
  判断し、本フェーズでは対象外とした。
