# おしえんパシャっと

アイドル・声優・2.5次元舞台・eスポーツ大会等の遠征参加者(ファン)向けに、当落確定後の
短い情報(会場・日時・予算感・物販希望等)を送るだけで、AIが(1)遠征プラン下書き(交通手段・
宿泊候補エリアの当たりをつけたもの)、(2)当日タイムテーブル草案(開場・グッズ列を踏まえた
もの)、(3)遠征費用の内訳見積り、の3つをまとめて生成するサービス。

ideas.md 2026-10-28 08:00 UTC記載「おしえんパシャっと」を基に、新規venture folderとして
今回立ち上げた(既存6venture=aircon-pasha・course-set-pasha・kura-pasha・forklift-pasha・
line-reservation-ai・event-komiguai-pashaはいずれもB2Bの「作業後一次対応文書生成」系だが、
本ventureはB2Cの個人消費者(ファン)向けという異なる顧客層・利用シーンを扱う)。

## 概要

- 対象顧客: アイドル・声優・2.5次元舞台・eスポーツ観戦等の遠征(現地参加)を行う個人のファン層で、
  旅行代理店を使わず自力で遠征計画を立てている人(B2C)。
- 入力: 当選公演の会場・日時・枚数、予算感、現地でのグッズ購入希望(発売形式・個数上限等)、
  前後の予定(有給消化の可否等)。
- 出力: (1)遠征プラン下書き(交通手段・宿泊候補エリアの当たり。実際の予約は本人が行う)、
  (2)当日タイムテーブル草案(開場時間・グッズ列を踏まえたもの)、(3)遠征費用(交通・宿泊・
  物販予算)の内訳見積り、(4)複数公演「ハシゴ」時の移動無理チェック。
- 実際の交通機関・宿泊施設の予約・決済自体は本人が行う前提とし、本サービスは計画下書きの
  生成支援のみを行う(具体的な空席・空室の実在確認や決済代行は行わない)。会員管理・
  予約受付・決済は当面扱わない。

## 他ventureとの構成上の違い(初期仮説)

- 既存6venture(特にaircon-pasha・course-set-pasha)は「1メモ受信→LLM呼び出し→複数テキスト
  生成→即時返信」という単純なリクエスト/レスポンス型だが、本ventureは入力項目が
  (会場・日時・予算・物販希望等)複数にわたり、かつ会場ごとの固有情報(最寄り駅・開場時間の
  目安・グッズ列の傾向)を参照する必要がある可能性があるため、単純な1リクエスト型で
  足りるか、簡単な会場マスタ(主要会場の最寄り駅・アクセス情報のみを保持する軽量な参照
  データ)を持つ必要があるかは次回以降の検討課題とする。
- B2Cかつ利用シーンが「チケット当落発表後の短期間」に集中するため、line-reservation-aiの
  ような継続利用(予約管理)ではなく、course-set-pashaに近い都度利用(課金単位も「当選1件
  あたり1回」が候補)になる見込み。料金プラン・利用頻度の仮説は次回以降に検討する。
