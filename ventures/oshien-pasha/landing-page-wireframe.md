# ランディングページ(LP)ワイヤーフレーム(フェーズ31)

landing-page-copy-draft.md(フェーズ30)の「次のステップ候補」(1)で挙げていたワイヤーフレーム
(セクション配置・画像イメージ)を作成する。他venture(aircon-pasha・course-set-pasha・
kura-pasha・line-reservation-ai・event-komiguai-pasha)には既に存在するが本ventureには無かった
cross-venture parityのギャップに対応するもの。他venture同様、実装(HTML/CSS)は行わずテキスト
ベースのワイヤーフレームに留める。LP実装(landing-page/index.html)・公開自体は引き続き別の
課題(次のステップ候補(1))とする。

## 設計方針

- 想定読み手(アイドル・声優・2.5次元舞台・eスポーツ観戦等の遠征を自力で計画する個人のファン)
  は、当落発表直後にスマートフォンで即座に確認する比率が高いと想定し、他venture同様モバイル
  1カラムを基本レイアウトとする。
- landing-page-copy-draft.mdのセクション順(ファーストビュー→課題提起→解決策・機能紹介→
  差別化→料金・トライアル→FAQ)をそのまま画面の縦の並びとする。
- 本venture固有の2点を画像・視覚要素で明示する:
  (1)「当落発表→短時間で遠征計画」という切迫感を、他ventureの「依頼者への説明づくり」とは
  異なる訴求軸として、時計・カレンダーのイメージと共にヒーローセクションで強調する。
  (2)1入力(当選情報メモ)→4出力(遠征プラン下書き・タイムテーブル草案・費用見積り・
  ハシゴ無理チェック)という対応関係を、event-komiguai-pashaと同系統の「メモ1件→出力カード
  複数分岐」の画像で見せる。
- 会場名寄せ不一致・休館時の留保、月額フリーパスの解約方式(期間終了時)は断定しない表現を
  FAQセクションに集約し、他セクションでは言及しない方針(landing-page-copy-draft.mdの方針を
  そのまま踏襲)。

## 画像・ビジュアル方針まとめ

| セクション | 画像案 | 備考 |
|---|---|---|
| ヒーロー | 当選メモ1件→4種の出力カードへの分岐(矢印4分岐)+時計/カレンダーアイコン | 最優先で作る画像。「当落発表→短時間」の切迫感と、本venture固有の「1入力→4出力」構成を1画面で伝える |
| 課題提起 | 画像なし(テキスト+チェックアイコンのみ) | 共感重視、視覚要素は最小限(他venture同様) |
| 解決策・機能紹介 | 6項目に対応する番号アイコン、⑤に注意喚起トーンの吹き出し、⑥のみ区別枠 | ハシゴ無理チェックの「断定しない」注記を目立たせつつ威圧的にならない表現にする。⑥は「やらないこと」の明示を視覚的にも区別 |
| 差別化 | 画像なし | テキスト訴求のみで十分と判断(他venture同様) |
| 料金・トライアル | 画像なし | 数字とチェックリストで訴求(2プラン併記) |
| FAQ | 画像なし | アコーディオン形式、他venture同様 |
