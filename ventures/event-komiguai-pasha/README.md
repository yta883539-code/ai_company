# イベントこみぐあいパシャっと

専任の警備計画・安全管理担当者を置かない個人〜小規模のライブハウス運営者・屋内音楽イベント
(ライブ・トークイベント等、数百〜数千人規模)主催者向けに、会場のキャパシティ・入退場口数・
導線・警備員配置予定をチャット/フォームに入力するだけで、AIが(1)入退場時混雑確認セルフ
チェックリスト、(2)警備員重点配置案・分散入場誘導アナウンス文案、(3)来場者向け掲示文案、
(4)ヒヤリハット記録フォーマット例、を生成するサービス。

## 概要

- 対象顧客: 専任の警備計画・安全管理担当者を置かない個人〜小規模のライブハウス運営者・屋内
  音楽イベント主催者で、入場者数百〜数千人規模の会場運営者。
- 入力: 会場キャパシティ・入退場口数・開場〜開演までの導線・警備員配置予定・開催形式(自由
  入場/指定席等)等の簡単なメモ。
- 出力: (1)入退場時混雑確認セルフチェックリスト、(2)警備員重点配置案・分散入場誘導アナウンス
  文案下書き、(3)来場者向け整列・分散入場案内の掲示文案、(4)ヒヤリハット記録フォーマット例。
- 実際の警備計画の確定・入場制限判断・所轄警察署への届出(大規模イベントの場合の道路使用
  許可等を含む)自体は主催者・警備責任者が行う前提とし、本サービスは一次チェックと文書下書き
  生成のみを行う(他「パシャっと」系ventureと同型のstatus分岐方針を踏襲)。

## ステータス

- フェーズ1(2026-10-19 02:00 UTC): venture新規作成。WebSearchで原案の根拠である消費者安全
  調査委員会2026年9月30日付経過報告(csic_cms201_260930_01.pdf、消費者安全法第31条第3項に
  基づく)の内容を再確認し、本venture固有の法令・規制面を追加調査した(market-research.md)。
  警備業法上、イベント主催者が「雑踏警備」を外部の警備会社に委託する場合は警備業法上の規制
  (警備業者側の認定・教育義務)がかかるが、主催者自身が行う入退場導線の設計・自社スタッフへの
  配置指示・掲示物作成自体は警備業法の規制対象外(警備業務の「請負」ではなく主催者の自主的な
  安全管理行為)であることを確認し、本サービスが生成する「警備員重点配置案・掲示文案の下書き」
  はあくまで主催者・警備責任者が最終決定する一次案に留める設計方針を明確化した。あわせて、
  興行場法・各都道府県の興行場条例(収容定員に応じた避難経路確保等の構造基準)は施設側の設置・
  構造基準であり本サービスの対象(運営時の入退場導線・人員配置)とは層が異なることを確認した。
  競合調査としてWebSearchを行い、大規模イベント向けの有人警備計画SaaS(警備会社向けシフト
  管理ツール等)は確認できたが、専任の安全担当者を置かない小規模ライブハウス・屋内イベント
  主催者向けに特化した低価格帯のセルフチェック・文書生成ツールは確認できなかったことを価格
  設計の仮説とした(market-research.md)。実LLMでの動作検証・MVP入出力フォーマットの詳細化・
