# イベントこみぐあいパシャっと

専任の警備計画・安全管理担当者を置かない個人〜小規模のライブハウス運営者・屋内音楽イベント
(ライブ・トークイベント等、数百〜数千人規模)主催者向けに、会場のキャパシティ・入退場口数・
導線・警備員配置予定をチャット/フォームに入力するだけで、AIが(1)入退場時混雑確認セルフ
チェックリスト、(2)警備員重点配置案・分散入場誘導アナウンス文案、(3)来場者向け掲示文案、
(4)ヒヤリハット記録フォーマット例、を生成するサービス。

## 概要

- 対象顧客: 専任の警備計画・安全管理担当者を置かない個人〜小規模のライブハウス運営者・屋内
  音楽イベント主催者で、入場者数百〜数千人規模の会場運営者。
- 入力: 会場キャパシティ・入退場口数・開場〜開演までの導線・警備員配置予定・開催形式(自由
  入場/指定席等)等の簡単なメモ。
- 出力: (1)入退場時混雑確認セルフチェックリスト、(2)警備員重点配置案・分散入場誘導アナウンス
  文案下書き、(3)来場者向け整列・分散入場案内の掲示文案、(4)ヒヤリハット記録フォーマット例。
- 実際の警備計画の確定・入場制限判断・所轄警察署への届出(大規模イベントの場合の道路使用
  許可等を含む)自体は主催者・警備責任者が行う前提とし、本サービスは一次チェックと文書下書き
  生成のみを行う(他「パシャっと」系ventureと同型のstatus分岐方針を踏襲)。
