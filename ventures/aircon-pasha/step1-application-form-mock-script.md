# ステップ1(申込フォーム入力)のモック画面スクリプト

## 位置づけ

step3-trial-generation-mock-script.md「次のステップ候補」が挙げていた「ステップ1(申込
フォーム入力)・ステップ5(本番運用時のメモ送信)についても同様のモックスクリプトを
作成し、onboarding-guide.mdから参照できる形にまとめる」に対応し、本フェーズではステップ1
を対象とする(ステップ5は引き続き次回以降の課題)。onboarding-guide.md 1.「申込・トライ
アル開始」およびapplication-form-submission-http-entry-point-design.mdの入力項目定義を
素材に、業者がLP経由で申込フォームに入力し、サンクスページで連携コードを受け取るまでの
画面の見え方を文章で再構成したモック台本である。実際のフォーム実装・送信・連携コード発行は
行っておらず、新しい事実確認・WebSearch調査も行っていない。

## モック対象ケース

onboarding-guide.md 1.記載の入力項目(屋号・事業形態〈任意〉・連絡先メールアドレス)と、
user-account-linking-design.md 2節の6文字連携コード発行方式(`pending_links/{code}`)に
基づき、candidate-longlist-draft.mdの区分例から「独立系のエアコンクリーニング業者」を
想定ケースとして用いた。メールアドレス・屋号は架空の例であり実在の事業者を示すものではない。

## 画面の見え方(案)

```
[LP(landing-page-copy-draft.md)下部の申込フォーム]

┌─────────────────────────────┐
│ 無料トライアルをはじめる              │
│                                │
│ 屋号・事業者名 *                   │
│ [ 〇〇エアコンクリーニング            ] │
│                                │
│ 事業形態(任意)                   │
│ ( ) 独立系   ( ) フランチャイズ加盟      │
│ ( ) 複合メニュー業者のエアコン部門        │
│                                │
│ 連絡先メールアドレス *                │
│ [ example@example.com            ] │
│                                │
│ ※この時点ではクレジットカード登録は不要です。  │
│   14日間、または生成10回のいずれか早い方まで  │
│   無料でお試しいただけます。             │
│                                │
│        [ 無料トライアルを開始する ]      │
└─────────────────────────────┘

(送信後、サンクスページへ遷移)

┌─────────────────────────────┐
│ お申込みありがとうございます             │
│                                │
│ 下記の連携コードを、LINE公式アカウントを    │
│ 友だち追加後、最初のトークでそのまま送信     │
│ してください。                       │
│                                │
│         連携コード: 7F3KD2           │
│                                │
│ [ LINE公式アカウントを友だち追加する ]     │
└─────────────────────────────┘
```

## 注記・限界

- 連携コード「7F3KD2」は表示イメージ用の架空の値であり、実際に
  `pending_links/{code}`へ発行されたものではない。実装(フェーズ107〜113、
  prototype/user_id_linking.py)はランダム6文字生成のロジックを持つが、本モックは
  そのロジックを呼び出さず文面化しただけである。
- フォームのレイアウト(項目順・ラベル文言)はapplication-form-submission-http-entry-
  point-design.md・onboarding-guide.md 1.の記述に基づくが、実際のLP実装(HTML/CSS)は
  行っていない。landing-page-wireframe.mdとの体裁の整合は今後の課題として残す。
- ステップ5(本番運用時のメモ送信)は引き続き本フェーズでは対象外。ステップ2(友だち
  追加・連携コード送信)は実アカウント名・QRコードを要するため実LINE API接続(オーナー
  承認待ち)にあわせて着手する方針(step3-trial-generation-mock-script.md・
  onboarding-guide.md記載の通り変更なし)。
