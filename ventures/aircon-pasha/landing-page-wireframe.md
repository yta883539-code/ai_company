# ランディングページ(LP)ワイヤーフレーム

landing-page-copy-draft.mdの「次のステップ候補」で挙げていたワイヤーフレーム(セクション配置・
画像イメージ)を作成する。course-set-pasha・line-reservation-aiと同様、実装(HTML/CSS)は
行わずテキストベースのワイヤーフレームに留める。LP実装・公開自体は「公開」に該当するため
引き続きオーナー承認後の課題とする。

## 設計方針

- 想定読み手(フランチャイズ加盟・独立系のエアコンクリーニング専門業者)は施工の合間・
  移動中にスマートフォンで閲覧する比率が高いと想定し、line-reservation-ai・course-set-pasha
  と同様にモバイル1カラムを基本レイアウトとする。
- landing-page-copy-draft.mdのセクション順(ヒーロー→課題提起→機能紹介→「ゼロから
  説明しなくていい」→料金・トライアル→FAQ)をそのまま画面の縦の並びとする。
- 画像方針は他ventureと異なる。line-reservation-ai・course-set-pashaはLINEトーク画面や
  SNS投稿画面のモックアップが差別化の核心だったが、本ventureは「依頼者への完了報告書・
  お手入れ案内メモ」という1対1の文書が成果物であるため、トーク画面ではなく「メモ入力→
  完了報告文」のビフォーアフター(入力メモの手書き風/簡易テキストと、生成された完了報告文を
  並べる構成)を軸にする。course-set-pashaのSNS投稿プレビュー、line-reservation-aiの
  トーク画面と役割が重複しないよう、本ventureは「業務メモ→整形済み文書」という変換過程を
  見せることに絞る。

## 画像・ビジュアル方針まとめ

| セクション | 画像案 | 備考 |
|---|---|---|
| ヒーロー | 入力メモ→完了報告文のビフォーアフター | 最優先で作る画像。「メモを送るだけ」の体験を1枚で伝える |
| 課題提起 | 画像なし(テキスト+チェックアイコンのみ) | 共感重視、視覚要素は最小限 |
| 解決策・機能紹介 | 5項目に対応する番号アイコン、5番目のみ区別枠 | 「やらないこと」の明示を視覚的にも区別 |
| 「ゼロから説明しなくていい」 | 画像なし | テキスト訴求のみで十分と判断 |
| 料金・トライアル | 画像なし | 数字とチェックリストで訴求 |
| FAQ | 画像なし | アコーディオンUIのみ |

CTAボタンは「14日間無料で試してみる」の文言・配置(ヒーロー/料金セクション/フッター前の計3箇所)で
統一し、line-reservation-ai・course-set-pashaと表記を揃えた。

## 未確定・今後の課題

- ビフォーアフター画像そのものの制作(実際のメモ例・完了報告文サンプルを使ったモックアップ
  デザイン)は本ワイヤーフレームのスコープ外。制作着手時にどのツール・素材を使うかは未検討
  (line-reservation-ai/aircon-pasha共通の課題として、Canva等外部デザインツール利用は
  アカウント連携が発生する場合オーナー確認が必要)。
