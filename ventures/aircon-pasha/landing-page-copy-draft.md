# サービス紹介ランディングページ(LP)コピー草案

market-research.md(競合・代替手段の仮説)・pricing-plan.md(料金プラン・無料トライアル条件)・
sns-blog-example-observation.md(実例観察)・legal-notices-draft.md(特商法・プライバシー
ポリシー草案)を踏まえ、想定顧客(フランチャイズ加盟・独立系を問わず個人〜小規模で活動する
エアコンクリーニング専門業者)向けに、サービス自体を紹介するLPのコピー草案を初めて作成する。
course-set-pasha/landing-page-copy-draft.mdと同じ構成(ヒーロー→課題提起→機能紹介→
差別化→料金→FAQ)を踏襲しつつ、本venture固有の「宛先が依頼者本人1名(SNS不特定多数では
ない)」「冷媒・電気系統には踏み込まない」という特性を反映する。実際のLP実装・公開は行わず、
文言の草案のみ。

## 想定する読み手

- フランチャイズ加盟・独立開業を問わず個人事業主として活動するエアコンクリーニング
  (分解洗浄)専門業者。
- ハウスクリーニング業者の中でもエアコン分解洗浄を主力メニューとする個人事業主。
- 繁忙期(梅雨〜夏)は施工件数が増える一方、依頼者向けの完了報告・お手入れ案内の言語化に
  割ける時間が相対的に短くなる(market-research.mdの課題仮説に対応)。

## ファーストビュー(ヒーローセクション)

```
見出し: 分解洗浄が終わったら、あとはメモを送るだけ。
サブ見出し: 完了報告もお手入れ案内も、AIが下書きします。
CTAボタン: 14日間無料で試してみる(カード登録不要)
```
- course-set-pashaが「投稿文・告知文づくりをAIに任せる」だったのに対し、本ventureの主語は
  「依頼者への説明づくりをAIに任せる」。施工そのものの主語は業者本人のまま変えず、
  AI・システムという言葉はヒーローセクションでは使わない方針を踏襲。
- CTA直下の「カード登録不要」はpricing-plan.mdの無料トライアル条件をそのまま反映。

## 課題提起セクション

```
見出し: こんなことに、時間を取られていませんか?
- 繁忙期(梅雨〜夏)、完了報告の文章を考える時間が施工の合間に取れない
- 「どこまで分解洗浄したか」「防カビコートは入れたか」を、依頼者ごとに毎回書き直している
- 「次はいつ頼めばいい?」「自分で手入れしていい?」という質問に、口頭でその場しのぎの説明を
  している
- 号数・機種系統・汚れ状況・防カビコートの有無の記録が、施工件数が増えるほど後回しになる
```
- market-research.mdの「課題(ペインポイント)の仮説」3点(完了報告の言語化負荷・依頼者からの
  定型質問対応・施工履歴の属人化)を一人称の悩みに変換。3項目目はmvp-flow-draft.mdの出力2
  (お手入れ案内)、4項目目は出力3(履歴記録)にそれぞれ対応させ、次の機能紹介セクションへの
  伏線とする。

## 解決策・機能紹介セクション

```
見出し: 「エアコンパシャッと」がやること
1. 号数・分解洗浄の範囲・汚れ状況・追加施工の有無をメモで送るだけ
2. 依頼者向けの作業完了報告メッセージを、実施範囲・使用した洗浄剤や防カビコートの
   有無つきで自動生成します
3. お手入れ案内(フィルターの自己清掃目安・次回分解洗浄の推奨時期)の下書きも同時に生成します
4. 「いつ・どの機種を・どんな状態で」施工したか、履歴記録も1行分まとめて作成します
5. 冷媒ガスの取り扱いや電気系統についての専門的な助言は、行いません
```
- 2・3項目目はmvp-flow-draft.mdの出力1(完了報告)・出力2(お手入れ案内)、4項目目は出力3
  (履歴記録)、5項目目はllm-system-prompt-draft.mdの厳守事項(冷媒・電気系統への専門的助言
  回避)にそれぞれ対応させ、既存設計と齟齬がないようにした。course-set-pashaのLPが
  「誤情報を書かない」ことを安心材料としたのに対し、本ventureは「専門外の判断に踏み込まない」
  ことを安心材料とする(依頼者の安全に直結する分野のため、線引きの明確さを最優先の訴求点とした)。

## 「ゼロから説明しなくていい」を強調するセクション

```
見出し: 汎用AIツールへの説明、もう不要です
号数も機種系統も防カビコートの有無も、いつも使っている言葉のままメモに書くだけで伝わります。
ChatGPT等に毎回ゼロから業界用語を説明する手間はありません。
```
- market-research.mdの「競合・代替手段の仮説」(汎用チャットAIとの比較優位点、独立系業者には
  フランチャイズ本部のような報告書テンプレート支援がないという指摘)をLP向けの短い文に
  落とし込んだもの。course-set-pashaの同セクションと同じ位置づけで、価格訴求より先に体験の
  違いを提示する。

## 料金・トライアル訴求セクション

```
見出し: まずは14日間、無料でお試しください
- クレジットカードの登録は不要です
- 14日間、または生成10回到達のいずれか早い方まで無料でご利用いただけます
- 期間終了後に自動で課金されることはありません。ご利用実績(生成回数・浮いた作業時間の目安)
  をお送りしますので、続けたい場合のみプランをお選びください
月額2,980円〜(月間生成回数に応じたプランをご用意しています。繁忙期に施工件数が増える方
```

  pricing-plan.mdの季節性への言及を踏まえた表現。

## よくある質問(FAQ)セクション(案)

```
Q. フランチャイズ加盟なのですが、使えますか?
A. はい。フランチャイズ加盟・独立系を問わずご利用いただけます。ただし本部が既に報告書
   テンプレートを提供している場合は、そちらとの使い分けをご検討ください。

Q. 写真を送らないと使えませんか?
A. 写真は必須ではありません。メモだけでも完了報告・お手入れ案内を生成できます。

Q. 冷媒ガスの補充や電気系統の不具合についても案内してもらえますか?
A. いいえ。冷媒ガスの取り扱いや電気系統に関する専門的な助言は行いません。実際の分解洗浄
   作業・機種判別・冷媒に関する専門的判断は、これまで通りご自身で行っていただきます。
   本サービスは完了報告・お手入れ案内文の下書き作成のみをお手伝いします。

Q. LINEをブロック(友だち解除)すれば解約したことになりますか?
A. いいえ。LINEのブロックとご契約の解約は別のお手続きです。ブロックのみではご請求は
   止まりません。ご契約を終了されたい場合は、LINEで「解約したい」とお送りいただくか、
   お申し込み時にご案内する解約手続きページから直接お手続きください。
```
- 1問目はmarket-research.mdの「競合・代替手段の仮説」(フランチャイズ本部支援の有無)を
  FAQでも明示し、想定読み手の双方(フランチャイズ加盟・独立系)に配慮した。3問目は
  README.mdの前提(「冷媒ガスの取り扱いや電気系統に関する専門的助言は行わない」)を
  FAQでも明示し、全自動化・専門助言への過度な期待を予防する狙い(course-set-pashaの
  FAQ3問目「グレードやセット内容の最終判断」と同じ位置づけ)。4問目はunfollow-billing-
  faq.md(フェーズ165)で整理した「ブロックと解約は別手続き」の周知文言で、ブロック後に
  LINE経由の案内が送達不可になる前に解約を促す狙い(course-set-pashaと同一方針)。

## 未検証の仮説・要検証事項

- 「ゼロから説明しなくていい」という体験差別化と、「月額2,980円〜」という価格、どちらを
  先に見せた方が申し込み転換率が高いかは未検証(現時点では体験差別化を先に置く仮の順序、
  course-set-pashaと同じ判断)。
- AI利用の開示表示義務の要否は、legal-notices-draft.mdの未検証事項(依頼者個人情報の
  誤記載対応方針)と合わせて法律専門家への相談が必要な可能性があり、本ドキュメントの
  範囲では結論を出さない。
- 実際のLP公開にはドメイン取得・ホスティング・特定商取引法に基づく表記の【要記入】項目
  確定が必要で、これらは「公開」に該当するため着手時は別途オーナー承認が必要
  (pending-approval.md参照)。
