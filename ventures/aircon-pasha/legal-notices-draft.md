## 1. 特定商取引法に基づく表記(案)

本サービスは月額課金のSaaS(役務提供)であり、通信販売の「商品」の売買ではないが、
継続的な役務提供契約として特定商取引法の表示義務(通信販売に準じた運用)の対象と
なりうるため、以下の項目を用意する。line-reservation-ai・course-set-pashaの
legal-notices-draft.mdで整理した「役務提供契約も通信販売の表示義務の対象に含まれる
可能性が高い」という調査結果は、サービス形態(月額課金のテキスト生成SaaS)が共通する
ため本ventureにもそのまま準用できると考えられる。

| 項目 | 内容(案) |
|---|---|
| 事業者名 | 【要記入】(個人事業主の場合は屋号+代表者氏名、法人の場合は商号) |
| 代表者 | 【要記入】 |
| 所在地 | 【要記入】(他venture同様、自宅住所の常時表示要否は専門家確認が必要な未確定事項) |
| 連絡先(電話番号・メールアドレス) | 【要記入】 |
| 販売価格 | pricing-plan.mdのプラン案に準拠。「月額2,980円〜(税込)、プラン詳細は申込フロー内で提示」 |
| 支払方法 | クレジットカード決済(決済代行サービス経由を想定、具体的な決済代行事業者の選定は未着手) |
| 支払時期 | 無料トライアル終了後、本人が有料プランを選択した時点から月次自動課金(トライアル条件の詳細はpricing-plan.md「次のステップ候補」の検討課題として残っており未確定) |
| 提供時期 | 申込完了後、LINE公式アカウントまたは入力フォームの連携設定完了次第、即時利用開始 |
| 返品・キャンセルについて | 役務提供(SaaS利用)のため物理的な返品はなし。契約者はいつでも次回請求サイクル分から解約可能。日割り返金は行わない旨を明記(要確定) |
| 動作環境 | LINE公式アカウントまたはWebフォーム等、業者が作業後メモを送信する手段(本サービスは完了報告・お手入れ案内・履歴記録の下書き生成のみを行い、実際の依頼者への送付は業者本人が行う設計) |

- 「所在地の常時表示要否」「返金ポリシーの詳細」は法律専門家への確認が必要な未確定事項として残す(他venture共通)。
- 決済代行サービスとの加盟店契約には、この特商法表記の整備が前提条件となる(決済代行事業者の選定自体が本ventureの未着手事項)。

## 2. プライバシーポリシー(案)

### 2.1 取得する情報

- 業者が入力する情報: 作業後メモ(号数・機種系統・汚れ状況・防カビコート有無・次回推奨時期等、
  mvp-flow-draft.md記載の入力フォーマットに準拠。依頼者(エンドユーザー)個人を特定する氏名・
  住所等の記入は想定しないが、業者が任意にメモへ含めてしまう可能性はあるため、取扱い方針を
  利用規約で明示する必要がある)
- 課金に関する情報: 決済代行サービス経由のクレジットカード情報(本サービス側では非保持、
  決済代行事業者が管理)
- 本サービスは依頼者(エンドユーザー)本人とのLINE会話やSNS投稿文の生成は扱わず、業者から
  業者自身への完了報告・お手入れ案内の下書き作成に特化しているため、依頼者個人の連絡先・
  LINEユーザーID等は原則取得しない設計とする。

### 2.2 利用目的

- 依頼者向け作業完了報告メッセージ下書き・お手入れ案内下書き・簡易な作業履歴記録の生成、
  本サービスの提供に必要な範囲での利用
- LLM(生成AI)API(Claude API等)への問い合わせを通じた、入力メモの解釈・下書き文生成
- サービス改善のための統計的な利用状況分析(個人を特定しない形での集計に限定する方針)

### 2.3 第三者提供・委託

- 入力メモの解釈・下書き文生成のため、外部のLLM APIプロバイダ(Claude API等)に入力内容を
  送信する。プロバイダ側のデータ取り扱い方針(学習利用の有無等)を確認の上、利用規約・
  プライバシーポリシーに委託先として明記する必要がある(現時点でAPIプロバイダ未契約のため
  詳細は今後確認)。
- 決済情報は決済代行サービスに直接入力・管理され、本サービス運営者はカード番号等を保持しない。
- 法令に基づく開示要請があった場合を除き、上記以外の第三者への提供は行わない。

### 2.4 保存期間・削除

- 契約終了後の入力メモ・作業履歴記録の保存期間(案: 契約終了から◯ヶ月後に削除)は未確定。
  本ventureはline-reservation-aiのfirestore-data-model.md相当のデータ設計ドキュメントを
  まだ作成していないため、データ保存方式の確定と合わせて検討する必要がある。
- 業者からの開示・削除請求への対応窓口(連絡先)を明記する。

### 2.5 未検証・要確認事項

- LLM APIプロバイダとの契約内容(データ学習への利用有無、保存期間、国外移転の有無)は
  APIプロバイダ契約後でないと確定できないため、pending-approval.md記載の
  「実LLM API投入」の承認・契約後に本節を更新する必要がある。
- 「AIが下書き生成に関与していることの開示要否」は、line-reservation-aiのlegal-notices-draft.md
  2.5節で整理した調査結果(日本法上は一般的な義務なし)を準用できると考えられる。本サービスは
  course-set-pashaと異なりSNS投稿文のような対外広告的な発信は生成せず、業者から依頼者への
  一対一の完了報告・お手入れ案内(line-reservation-aiの一対一案内文に近い性質)にとどまるため、
  course-set-pashaで独自に再整理が必要とされたステルスマーケティング規制との関係は本venture
  では該当性が薄いと考えられる。あくまでWeb調査による一般的な傾向整理であり法的助言ではないため、
  最終的な要否判断は法律専門家への確認が必要。
- 完了報告・お手入れ案内文に、依頼者の氏名・住所等の個人情報を業者が誤ってメモへ記載してしまう
  ケースへの対応方針(本サービス側でのマスキング要否等)は、post_generation_checks.pyの
  既存チェック関数の対象外であり、新たな検討課題として残る。
