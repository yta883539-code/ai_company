# サービス紹介ランディングページ(LP)コピー草案

market-research.md(差別化ポイント)・pricing-plan.md(料金プラン・無料トライアル条件)・
tone-and-manner-guideline.md(数字表記・絵文字ルール等)を踏まえ、想定顧客(美容室・整体院・
パーソナルジム・個人講師業のオーナー)向けに、サービス自体を紹介するLPのコピー草案を初めて作成する。
これまでの成果物は「顧客とのLINE上のやり取り」の設計が中心だったが、本ドキュメントは
「オーナーが本サービスを知って申し込むまで」の導線で使う文言を扱う点で新規領域。
実際のLP実装・公開は行わず、文言の草案のみ。

## 想定する読み手

- 美容室・整体院・パーソナルジムなどを1人〜数人で経営するオーナー。
- 予約対応(電話・LINE個別返信)に時間を取られている、または二重予約・無断キャンセルに悩んでいる。
- 新しいアプリ・システムを覚えるのが面倒で、「今使っているLINEのままで完結してほしい」と感じている
  (market-research.mdの想定ターゲット像・差別化ポイント1に対応)。

## ファーストビュー(ヒーローセクション)

```
見出し: 予約対応、もうLINEに任せませんか?
サブ見出し: お客様はいつものLINEトークで予約。あなたは確認するだけ。
CTAボタン: 14日間無料で試してみる(カード登録不要)
```
- 「LINEに任せる」で主語を利用者(オーナー)側に置きつつ、tone-and-manner-guideline.mdの
  「主語はAIではなくお店」の方針を踏まえ、AI・システムという言葉はヒーローセクションでは使わない。
- CTA直下に「カード登録不要」を添え、pricing-plan.mdの無料トライアル条件(クレジットカード登録なし)
  を訴求し、申し込みの心理的ハードルを下げる。

## 課題提起セクション

```
見出し: こんなことに、時間を取られていませんか?
- 施術中に予約の電話が鳴って、手が離せない
- 「あの日空いてますか?」への返信を、営業後にまとめて返している
- うっかり同じ時間に2件受けてしまった(二重予約)
- 前日リマインドを送り忘れて、無断キャンセルが増えている
```
- market-research.mdの「既存の代替手段と課題」(電話・LINE個別対応での取りこぼし・二重予約)を
  そのまま顧客の一人称の悩みに変換。箇条書き4項目のうち後半2つはdouble-booking-prevention.md・
  reminder-timing-and-resend-rules.mdで設計済みの機能に直接対応させ、機能セクションへの伏線とする。

## 解決策・機能紹介セクション

```
見出し: 「予約とれる君」がやること
1. お客様のLINEメッセージをAIが読んで、空いている日時を自動でお答えします
   (例: 「来週の土曜の午後空いてますか?」→ 候補を提示)
2. 日時が決まったら、仮押さえ→確定まで自動で進みます。ダブルブッキングの心配はありません
3. 前日には自動でリマインドを送るので、送り忘れがなくなります
4. よくある質問(住所・駐車場・支払い方法など)にも自動でお答えします
5. AIだけで対応しきれない相談は、その場であなたに通知が届きます
```
- 4項目目はfaq-response-templates.md・faq-escalation-boundary.mdの9a(FAQ)機能、
  5項目目は厳守事項6・10のエスカレーション通知機能にそれぞれ対応させ、既存設計と齟齬がないようにした。
  「AIだけで対応しきれない場合は必ず人に引き継ぐ」ことを明示し、全自動化への過度な期待
  (誤解によるクレーム)を予防する狙い。

## 「いつものLINEのまま」を強調するセクション

```
見出し: 新しいアプリは、いりません
お客様は、普段お店とやり取りしているLINEのトーク画面から、そのまま予約できます。
新しい会員登録もアプリのダウンロードも不要。今までと同じ感覚で、予約が完了します。
```
- market-research.mdの差別化ポイント1・2をそのままLP向けの短い文に落とし込んだもの。
  汎用予約システム(STORES予約等)との比較優位点であり、価格訴求より先に配置する
  (価格で比較される前に体験の違いで差別化する狙い)。

## 料金・トライアル訴求セクション

```
見出し: まずは14日間、無料でお試しください
- クレジットカードの登録は不要です
- 14日間、または予約20件到達のいずれか早い方まで無料でご利用いただけます
- 期間終了後に自動で課金されることはありません。ご利用実績をLINEでお送りしますので、
  続けたい場合のみプランをお選びください
月額2,980円〜(予約件数・ご利用スタッフ人数に応じたプランをご用意しています)
```
- pricing-plan.mdの無料トライアル条件・料金プランをそのまま反映。「自動課金しない」設計方針
  (無断課金への不信感回避)をLP上でも明言し、申し込みのハードルを下げる。
- プラン名・金額の詳細比較表はLPには載せず「月額2,980円〜」の最低額のみ提示し、
  詳細は申し込みフローの中で案内する構成とした(初回接触での情報過多を避けるtone-and-manner-guideline.mdの
  「1メッセージ1用件」の考え方をLP構成にも応用)。

## よくある質問(FAQ)セクション(案)

```
Q. LINE公式アカウントを持っていなくても使えますか?
A. お申し込み時に新規開設のお手伝いをします。既にお持ちの場合はそのまま連携できます。

Q. お客様に「AIが対応している」と気づかれませんか?
A. お客様には店舗スタッフとやり取りしている自然な文面でお答えします。
   AIであることを前面に出す・隠すという運用は、店舗様のご判断にお任せしています。

Q. 難しい相談やクレームにも対応してくれますか?
A. 予約に関するやり取り以外のご相談は、その場でオーナー様に通知が届き、
   ご自身で対応いただく仕組みになっています。
```
- 2問目はtone-and-manner-guideline.mdの「主語はAIではなくお店」方針と、AI利用の開示に関する
  誠実性のバランスを取った回答案。表示の要否(特定商取引法・景品表示法等の観点でAI利用の明示が
  必要かどうか)は法的な確認が別途必要な未検証事項として残す。

## 未検証の仮説・要検証事項

- 「新しいアプリはいりません」という体験差別化と、「月額2,980円〜」という価格、
  どちらを先に見せた方が申し込み転換率が高いかは実際のABテストが必要(現時点では未検証のため順序は仮)。
- FAQセクション2問目(AI利用の開示)について、景品表示法・特定商取引法上の表示義務の要否を
  要確認(法律の専門家への相談が必要な可能性があり、本ドキュメントの範囲では結論を出さない)。
- 実際のLP公開にはドメイン取得・ホスティング・法人/個人事業の特定商取引法に基づく表記整備が必要で、
  これらは「公開」に該当するため着手時は別途オーナー承認が必要(pending-approval.md参照)。
