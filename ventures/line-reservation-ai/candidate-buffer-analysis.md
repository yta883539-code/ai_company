# 業種ごとの候補数の妥当性・追加候補確保の目安

interview-candidate-selection-criteria.md の「未検討事項」に挙げた
「業種ごとの候補数の妥当性(承諾率が想定より低い場合の追加候補確保の目安)」を検討する。
※本ドキュメントは目安・基準の設計のみ。実在店舗の特定・連絡・依頼は行わない。

## 前提

- customer-interview-design.md の目標: ヒアリング実施件数10件前後
- 対象業種: 美容室・理容室/整体院・エステ/パーソナルジム/学習塾・個人講師業 の4業種
- interview-candidate-selection-criteria.md の現行案: 業種ごとに10〜15件リストアップ→各業種2〜5件に絞り込み(目標の1.5〜2倍程度の候補を用意)

## チャネル別の想定承諾率(一般的な目安、実測値ではない)

一般的なBtoBのコールド営業・依頼における反応率の目安を参考に、
本件(見知らぬ相手への15分ヒアリング依頼、謝礼未確定)は通常の営業アプローチより
ハードルが高い(相手にとって直接的な利益が薄い)ため、やや保守的に見積もる。

| チャネル | 想定承諾率(目安) | 理由 |
|---|---|---|
| 電話(直接会話) | 10〜20% | その場で趣旨説明・質疑ができ、断りにくさもあるため相対的に高め。ただし営業電話と誤解され即断りされるケースも多い |
| メール・問い合わせフォーム | 3〜8% | 開封・既読自体が不確実で、返信の心理的ハードルも高い |
| LINE公式アカウント経由 | 5〜10% | 電話ほどの即時性はないが、メールより気軽に既読・返信されやすい |

上記より、業種横断での加重平均承諾率はおおむね5〜12%程度と見積もる
(電話中心なら上振れ、メール中心なら下振れ)。

## 必要候補数の試算

目標: 各業種で2〜3件のヒアリング成立(合計10件前後)を想定した場合、

- 承諾率10%と仮定 → 1件成立させるのに約10件への打診が必要 → 業種あたり20〜30件の打診が必要
- 承諾率20%(電話中心・好条件)と仮定 → 業種あたり10〜15件の打診で足りる

現行の「業種ごとに10〜15件リストアップ→2〜5件に絞り込み」という案は、
「絞り込んだ2〜5件全てに打診して1.5〜2倍のバッファ」という意味であれば
承諾率40〜65%相当を前提にしており、上記の保守的な想定(5〜20%)よりかなり楽観的。

## 修正提案

- 「絞り込み後の2〜5件に打診」ではなく、「業種ごとに10〜15件を一次リストアップした段階で、
  そのほぼ全件(除外条件に該当しないもの)に打診候補として保持しておく」方式に変更する。
- 打診は一度に全件へ送るのではなく、まず各業種5件程度に打診→承諾状況を見ながら
  段階的に残りの候補へ広げる「ウェーブ方式」を推奨(未回答者への催促や過剰な同時打診を避けるため)。
- 目標2〜3件成立/業種に対し、初回ウェーブの目安は業種あたり8〜10件程度への打診
  (承諾率10%換算で成立0.8〜1件、複数ウェーブでの積み上げを想定)。
- 電話を含めるかどうかで必要バッファが大きく変わるため、
  「未確定事項」の送信チャネル選定(initial-contact-message-draft.md)と本試算はセットで
  オーナーに確認するのが望ましい。

## 追加候補確保のトリガー基準(目安)

- 初回ウェーブ(業種あたり8〜10件打診)から3営業日経過して成立0件の業種は、
  追加で5〜10件の候補を同業種内でリストアップする。
- 全業種合計で成立が目標(10件前後)の半分(5件)に届かない状態が
  初回ウェーブ完了後も続く場合、業種の追加(対象業種の拡大)も含めてオーナーに相談する。

## 次にやること(候補)

  (テンプレート化した記録シートの用意)
- ウェーブ方式の打診間隔・催促可否のルール化(no-show-handling.md等の既存ルールとの整合)
