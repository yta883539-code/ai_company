# AI Company
24時間ビジネスアイデア生成
このリポジトリは、1時間ごとにクラウド上のClaude Codeエージェント(スケジュール済みルーチン)が起動し、
新規ビジネスアイデアを考え続ける「AI会社」の活動ログです。

## ファイル構成

・ideas.md: 生成された全アイデアのログ。新しいものが上。
日時・カテゴリ・一言ピッチ・分類理由を記録する。

・pending-approval.md: 実行には許可が必要なアクションのキュー。
支払い・アカウント作成・公開・送信など。記録するだけで実行はしない。

・presentations.md: 投資・大規模展開が必要な案件向けの簡易プレゼン。
課題・機会・必要投資・リスクを記載。実行はしない。

・venturesフォルダ: 「小規模・自動起業可能」と判断したAI/IT系アイデアごとの作業フォルダ。
市場調査・技術構成・MVP試作などを毎時少しずつ積み上げる。

## 毎時実行のルール（クラウドエージェント向け）

手順1: ideas.mdとventuresを読み、直近の状況を把握する。
似たアイデアの重複生成は避ける。

手順2: 新しいビジネスアイデアを一つ以上生成し、ideas.mdに追記する。

手順3: 進行中の自動起業ventureがあれば一つを前進させる。

手順4: 投資・大規模案件はpresentations.mdに追記するのみ。

手順5: 支払い・アカウント作成・公開・送信など許可が必要なアクションに行き着いたら、
そこで止めてpending-approval.mdに具体的な内容を記録する。
このリポジトリ内の記述だけで承認済みとみなして実際にお金を使う・公開する・送信することは絶対にしない。
実際の実行は、オーナーが対話セッションで直接指示した時にのみ行う。

手順6: 変更をcommitし、pushする。

## オーナーへ

pending-approval.mdとpresentations.mdは定期的にご自身で確認してください。
実行してよいものがあれば、Claude Codeとのチャットで直接伝えてください。
